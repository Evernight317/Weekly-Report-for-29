第7周周报：Shell 脚本编程入门
本周学习目标：认识 shell 脚本，学会变量、判断，写简单自动化脚本。
学习内容：
1. shell 脚本基础：脚本文件#!/bin/bash头部，赋予执行权限运行脚本。
2. shell 变量定义、使用变量；位置参数$1 $2。
3. if 条件判断，简单比较运算符；for 循环基础。
4. 练习小脚本：输出系统时间、遍历目录文件、简单判断文件是否存在。
遇到的问题：
1. 脚本运行报错，忘记给脚本增加执行权限。
2. shell 语法和 C 语言不一样，if 判断括号空格格式要求严格，空格写错直接报错。
3. 变量使用符号容易写错
问题解决：
1. 记住两种运行脚本方式：bash test.sh或者chmod +x ./test.sh。
2. 记住 shell 语法对空格非常敏感，照着示例格式写，注意括号前后空格。
3. 多写小例子调试，遇到报错看终端输出错误信息定位问题。
第8周周报：定时任务 crontab+日志基础
本周学习目标：掌握 Linux 定时任务，理解系统日志，学会简单查看分析日志，实现脚本定时自动执行。
学习内容：
1. crontab 定时任务基础概念，crontab 表达式分、时、日、月、周语法。
2. crontab 常用命令：crontab -e编辑任务、`crontab -l`查看任务、crontab -r删除任务。
3. 编写简单测试脚本，配置定时执行，比如每分钟输出日志、定时备份文件。
4. 系统日志存放目录/var/log，熟悉syslog、auth.log登录日志。
5. 使用`tail -f`实时跟踪日志输出。
遇到的问题：
1. crontab 定时任务配置完成但是没有执行，不知道排查方向。
2. cron 时间表达式容易写错位，分、时顺序搞混。
3. 日志文件内容巨大，全部打开查看效率很低。
问题解决：
1. 将脚本中输出重定向到日志文件，通过日志判断脚本是否运行；确认脚本有执行权限。
2. 抄写标准示例对照练习，牢记格式：分 时 日 月 周。
3. 使用tail、grep过滤关键信息，不直接 cat 大日志文件。
