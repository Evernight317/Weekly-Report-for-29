第3周周报：权限进阶 + Vim 编辑器入门
本周学习目标：了解chmod、chown；掌握 vim 基础操作，能够完成简单文本编辑。
学习内容：
1. chown修改文件属主属组；区分符号模式u/g/o/a修改权限。
2. 简单了解默认权限 umask 的概念。
3. Vim 三种模式：普通模式、插入模式、末行模式。
4. 基础操作：打开文件、i 进入编辑、esc 退回普通模式，保存:w、退出:q、强制保存退出:wq!。
5. 光标移动、简单删除、复制粘贴，练习编写简单文本文件。
遇到的问题：
1. 进入 vim 之后不知道怎么退出，模式之间来回切换混乱。
2. chown 修改所有者需要 root 权限，忘记加 sudo 命令报错。
3. umask 概念理解比较抽象。
问题解决：
1. 反复练习模式切换，牢记 esc 回到普通模式，再执行保存退出命令。
2. 修改文件所有者必须 sudo 提升权限。
3. umask 只做了解，不深挖复杂计算，先记住它控制新建文件默认权限。
第4周周报：查找检索、压缩解压、软件包管理
本周学习目标：学会在系统中查找文件，处理压缩包，会使用 apt 安装卸载软件。
学习内容：
1. 文件查找：find命令基础用法，按文件名查找；grep文本内容检索，管道|。
2. 压缩解压：gzip、bzip2、tar 打包解压，tar 常用参数。
3. Ubuntu apt 包管理器：apt update更新源，apt install安装软件，apt remove卸载软件。
4. 练习：查找系统中某个配置文件；打包自己的测试目录；安装小工具。
遇到的问题
1. find 命令参数多，记不住；管道符号理解不透彻。
2. tar 参数繁多，打包解压经常写错参数导致解压失败。
3. apt 下载软件速度慢，软件源没有更换。
问题解决
1. 记住常用示例，不需要死记全部参数，遇到可以查帮助文档man。
2. 整理 tar 常用模板，记住tar -zcvf打包，tar -zxvf解压。
3. 了解软件源概念，知道可以更换国内镜像源提升下载速度。
