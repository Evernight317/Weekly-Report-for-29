二、缓存套餐

1、Spring Cache

是一个框架，实现了基于注解的缓存功能，只需要简单地加一个注解，就能实现缓存功能

它提供了一层抽象，底层可以切换不同的缓存实现：EHCache、Caffeine、Redis



常用注解：

注解	说明

@EnableCaching	开启缓存注解功能，通常加在启动类上

@Cacheable	在方法执行前先查询缓存中是否有数据，如果有数据，则直接返回缓存数据；如果没有缓存数据，调用方法并将方法返回值放到缓存中

@CachePut	将方法的返回值放到缓存中

@CacheEvict	将一条或多条数据从缓存中删除









2、缓存套餐实现思路：

导入 Spring Cache 和 Redis 相关 maven 坐标

在启动类上加入 @EnableCaching 注解，开启缓存注解功能

在用户端接口 SetmealController 的 list 方法上加入 @Cacheable 注解

在管理端接口 SetmealController 的 save、delete、update、startOrStop 等方法上加入 CacheEvict 注解

\- \*\*功能\*\*：按页展示当前用户的历史订单，支持按订单状态筛选，返回订单基本信息 + 订单商品明细

\- \*\*核心逻辑\*\*：

&#x20; 2. 通过`BaseContext.getCurrentId()`获取当前登录用户 ID，只查当前用户的订单

&#x20; 3. 遍历每条订单，单独查询关联的`order\_detail`订单明细，封装到`OrderVO`返回

\- \*\*关键 SQL\*\*：动态条件查询（用户 ID、状态、时间范围模糊匹配），按下单时间倒序



\### 2. 订单详情查询



\- \*\*功能\*\*：根据订单 ID 查询单条订单的完整信息（基本信息 + 所有菜品 / 套餐明细）

\- \*\*核心逻辑\*\*：先查订单主表`orders`，再根据订单 ID 查`order\_detail`明细表，用`BeanUtils.copyProperties`把订单属性复制到`OrderVO`，补充明细列表返回



\### 3. 用户取消订单



\- \*\*业务规则\*\*：

&#x20; - 仅\*\*待付款 (1)、待接单 (2)\*\*状态可直接取消

&#x20; - 待接单状态取消需调用微信支付接口退款，支付状态改为「已退款」

&#x20; - 取消后订单状态改为「已取消」，记录取消原因、取消时间

\- \*\*核心逻辑\*\*：先查订单是否存在，校验状态≤2，待接单则触发微信退款，最后更新订单状态字段



\### 4. 再来一单



\- \*\*功能\*\*：把原订单里的所有商品重新加入购物车

\- \*\*核心逻辑\*\*：

&#x20; 1. 根据原订单 ID 查订单明细

&#x20; 2. 把每条明细（菜品 / 套餐信息、口味、金额）复制成购物车对象，绑定当前用户 ID

&#x20; 3. 批量插入购物车表`shopping\_cart`

一、Spring Task

1、介绍：Spring Task是Spring框架提供的任务调度工具，可以按照约定的时间自动执行某段代码。

2、作用：定时自动执行某段JAVA代码

3、cron表达式：本质就是一个字符串，通过cron表达式可以定义任务触发的时间

构成规则：分为6或7个域，由空格分隔开，每个域代表一个含义

每个域含义依次为：秒、分钟、小时、日、月、周、年（可选）

例如：2022年10月12日上午9点整对应的cron表达式为：0 0 9 12 10 ? 2022

注意：一般日和周不能同时出现，通常一个精确了，另一个就要写‘？’

4、cron表达式在线生成器：https://cron.qqe2.com/

&#x20;       // select \* from orders where status = ? and order\_time < (当前时间 - 15分钟)

&#x20;               orders.setStatus(Orders.CANCELLED);

&#x20;               orders.setCancelReason("订单超时，自动取消");

&#x20;               orders.setCancelTime(LocalDateTime.now());

&#x20;           }

&#x20;       }

&#x20;   }

&#x20;   /\*\*

&#x20;    \* 处理一直处于派送中状态的订单

&#x20;    \*/

&#x20;           }
