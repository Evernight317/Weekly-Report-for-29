\### 4、BigDecimal底层存储原理

```java

private final BigInteger intVal;    // 无标度值（去掉小数点后的完整整数）

private final int scale;            // 标度：小数点右边有多少位

private final transient long intCompact; // 压缩缓存：数值小的时候，直接存在long，提升性能

```

① `intVal`：本质BigInteger，以`signum+int\[]mag`形式存储去掉小数点后的完整整数。

② `scale`

\- `scale>=0`：代表小数位数。例：`intVal=314, scale=2` → 原数 $314×10^{-2}=3.14$

\- `scale<0`：代表数字末尾补0。例：`intVal=12, scale=-2` → $12×10^{2}=1200$

> 注意：

> `new BigDecimal("2.50")`：intVal=250，scale=2

> `new BigDecimal("2.5")`：intVal=25，scale=1

> 二者用`equals`判断不相等，用`compareTo`判断相等



③ `intCompact`：如果无标度整数很小，在long范围内，缓存到intCompact(long)，intVal可以为null；只有超出long范围，`intCompact = Long.MIN\_VALUE`，才启用intVal(BigInteger)。

	#正则表达式
一、作用
1. 校验字符串是否满足规则
2. 在一段文本中查找满足要求的内容

二、正则表达式语法
 1、字符类 —— 只匹配一个字符
| 写法 | 含义 |
| `[abc]` | 只能是a, b, 或c |
| `[^abc]` | 除了a, b, c之外的任何字符 |
| `[a-zA-Z]` | a到z A到Z，包括（范围） |
| `[a-d[m-p]]` | a到d，或m到p |
| `[a-z&&[def]]` | a-z和def的交集。为: d, e, f |
| `[a-z&&[^bc]]` | a-z和非bc的交集。（等同于[ad-z]） |
| `[a-z&&[^m-p]]` | a到z和除了m到p的交集。（等同于[a-lq-z]） |

> 注意：`&`符号要写成`&&`才表示**而且**的意思，若只写`&`，则单单表示一个字符`&`

 2、预定义字符 —— 只匹配一个字符
| 写法 | 含义 |
| `.` | 任何字符 |
| `\d` | 一个数字：`[0-9]` |
| `\D` | 非数字：`[^0-9]` |
| `\s` | 一个空白字符：`[\t\n\x0B\f\r]` |
| `\S` | 非空白字符：`[^\s]` |
| `\w` | `[a-zA-Z_0-9]` 英文、数字、下划线 |
| `\W` | `[^\w]` 一个非单词字符 |

 3、数量词
| 写法 | 含义 |
| ---- | ---- |
| `X?` | X，一次或0次 |
| `X*` | X，零次或多次 |
| `X+` | X，一次或多次 |
| `X{n}` | X，正好n次 |
| `X{n,}` | X，至少n次 |
| `X{n,m}` | X，至少n但不超过m次 |

常规代码使用
待校验字符串.matches("正则表达式");

> 注意：Java字符串中写正则，`\`需要转义写成`\\`，例：`\\d`代表正则里的`\d`
