五、前后接收

1、前端请求地址与后端接口地址并不一样，但前端请求后端可以接受，因为nginx反向代理，将前端发送的动态请求由nginx转发到后端服务器

2、优点：提高访问速度\&进行负载均衡\&保证后端服务安全

注：负载均衡指把大量的请求按照我们指定的方式均衡的分配给集群中的每台服务器

3、nginx反向代理的配置方式（nginx.conf文件）：

server{

&#x20;   listen 80;

&#x20;   server\_name localhost;



&#x20;   location /api/ {

&#x20;       proxy\_pass http://localhost:8080/admin/; #反向代理

&#x20;   }

}



&#x20;   4、nginx负载均衡的配置方式（nginx.conf文件）：

upstream webservers{

&#x20;   server 192.168.100.128:8080;

&#x20;   server 192.168.100.129:8080;

}



server{

&#x20;   listen 80;

&#x20;   server\_name localhost;



&#x20;   location /api/ {

&#x20;       proxy\_pass http://webservers/admin/; #负载均衡

&#x20;   }

}



&#x20;   5、nginx负载均衡策略

名称			说明

轮询			默认方式

weight		权重方式，默认为 1，权重越高，被分配的客户端请求就越多

ip\_hash		依据 ip 分配方式，这样每个访客可以固定访问一个后端服务

least\_conn		依据最少连接方式，把请求优先分配给连接数少的后端服务

url\_hash		依据 url 分配方式，这样相同的 url 会被分配到同一个后端服务

fair			依据响应时间方式，响应时间短的服务将会被优先分配

注意：

ThreadLocal 并不是一个 Thread，而是 Thread 的局部变量。

ThreadLocal 为每个线程提供单独一份存储空间，具有线程隔离的效果，只有在线程内才能获取到对应的值，线程外则不能访问。

ThreadLocal 常用方法：

public void set(T value)：设置当前线程的线程局部变量的值

public T get()：返回当前线程所对应的线程局部变量的值

public void remove()：移除当前线程的线程局部变量

1\. AI Agent 概念

AI Agent 是可自主行动的软件程序，以大语言模型 LLM 作为推理核心；能够感知环境、收集信息，自主决策并完成目标任务，具备自主性、交互、学习、多模态的特点。

Agent 四大核心模块：



Memory（记忆）：存储历史信息、对话与观测结果，分为短时 / 长时记忆；

Plan（规划）：拆解目标，制定分步执行计划；

Tools（工具）：调用外部能力，如搜索、数据库、pandas 等，弥补大模型知识与能力局限；

Action（行动）：执行动作，获取环境反馈。



2\. 提示工程（Prompt Engineering）

提示工程是优化提示词 Prompt、调整生成策略，提升大模型输出质量的工程方法。编写 Prompt 需要描述清晰、需求具体，减少模型猜测，持续调优提示词来拿到预期结果，是构建 Agent 的基础能力。



3\. Agent 运行范式 ReAct（Reason+Act，思考 + 行动）

对比三类范式：



Reason Only（仅思考，如 CoT 思维链）：只在模型内部推理，不与外部环境交互；

Act Only（仅行动，如 WebGPT）：直接执行动作，缺少显式推理；

ReAct：\*\*推理 + 行动交替循环\*\*。模型先思考 Reasoning，执行 Action 动作，接收环境 Observations 观测反馈，再继续推理，循环迭代直到完成任务，是 Agent 最主流框架。



4\. 代码实现思路（Action Agent 示例 NL2SQL）

基于大模型函数调用实现 Agent 的基础流程：

① 构建消息列表，写入 system 系统角色指令、user 用户问题；

② 请求大模型，模型判断是否调用工具；

③ 解析模型返回的 function\_call，执行对应工具（示例里生成 SQL 查询数据库）；

④ 将工具执行结果放回消息队列，继续交给大模型处理，循环直到输出最终答案。



5\. Agent 执行流程示例（Jarvis Agent）

通过结构化 JSON 输出，实现思考 - 行动分离：Agent 内部先做 thought 思考、自我反思，然后选择命令（search 搜索 /write\_file 写文件 /read\_file 读文件 /finish 完成），调用工具完成目标；任务完成后使用 finish 指令输出最终结果。
