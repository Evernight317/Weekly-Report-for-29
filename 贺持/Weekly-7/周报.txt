***【Unity导航组件】

一、导航网格
1、创建一个场景，再在Hierarchy面板右键，点击AI，点击NavMesh Surface，创建了一个导航空物体

2、点开NavMesh Surface，在右侧面板中点击Agent Type的Open Agent Settings，会出现一个面板

3、在这个面板的Agents部分，面板中的选项由上至下为：
Name
Agent Radius 		代理半径（指假设人物半径，注意台阶如果太窄但人物半径大，那人物可能无法导航到台阶上）
Agent Height 		代理高度（指假设人物高度）
Max Slope 		最大坡度（上方假设好的人物可以上的最大坡度）
Step Height		步高（上方假设人物每一步最高上多少高度）
Generated Off Mesh Links	生成分离网格链接
Drop Height			掉落高度
Jump Distance			跳跃距离

4、目前先只用到【代理半径】到【步高】的功能，设定好参数，在面板下方点击Bake，创建的场景会出现导航网格，且导航网格明显会与地面边缘空出一点距离，因为人物中心可以到达导航边缘




二、导航移动
1、创建一个命名为Player的物体（以胶囊体为例），为其添加Nav Mesh Agent组件

2、点击这个组件的Agent Type的Open Agent Settings，在新面板的Agents部分，由于人物有高矮胖瘦之分，因此不同人导航网格不同，点击Agent Type下方的+号可以添加新的代理人，给它们设置不同的代理半径和代理高度，设置好了后可以在角色对象的Nav Mesh Type选择角色的体型

3、观察到创建的胶囊体除了自身碰撞框外，还有一个外围的碰撞框，在Nav Mesh Type组件的Base Offset（基准偏移）可以调节这个外围碰撞框的上下位置

4、Nav Mesh Type组件的Steering（转向）部分各功能：
Speed（最大速度）
Angular Speed（角速度）
Acceleration（加速度）
Stopping Distance（停止距离）
Auto Braking（自动刹车，勾选后物体到达导航目的地会停下；不勾选则物体到达目的地后不会停，而是在目的地处乱晃）

5、Nav Mesh Type组件的Obstacle Avoidance部分各功能：
Radius（半径）
Height（高度）
Quality（质量，选择的质量越高，效果越好，但性能消耗越高）
Priority（优先级）

6、导航脚本
using System.Collections;using System.Collections.Generic;using UnityEngine;using UnityEngine.AI;//用导航组件则需此名词空间
public class PlayerNavMesh : MonoBehaviour
{
    private NavMeshAgent agent;
    void Start()
    {
        //获取代理组件
        agent=GetComponent<NavMeshAgent>();
    }

    void Update()
    {
        //如果按下鼠标
        if (Input.GetMouseButtonDown(0)) 
        {
            //获取点击位置
            Ray ray=Camera.main.ScreenPointToRay(Input.mousePosition);
            RaycastHit hit;
            if (Physics.Raycast(ray, out hit))
            {
                //点击位置
                Vector3 point = hit.point;
                //设置该位置为导航目标点
                agent.SetDestination(point);
            }
        }
    }
}



三、Nav Mesh Obstacle导航网格障碍物组件
1、给一个墙体添加NavMeshModifier组件，勾选Override Area，Area Type选择Walkable，再重新烘焙一下，就发现导航网格可以穿过该墙体了，运行时物体也可以直接穿过该墙体

2、再为该墙体添加Nav Mesh Obstacle组件，重新烘焙，发现导航网格依旧可以穿过墙体，但是运行时物体要导航到墙体对面时，越靠近墙体越慢，最后会被墙体挡住，说明此时墙体以及作为一个生效的障碍物了（注意，物体的代理半径过小时，可能会硬怼过去导致穿墙）

3、Nav Mesh Obstacle组件的功能（由上至下）：
Shape：形状，可选择Box（盒子）形状或Capsule（胶囊）形状
Center：中心（一般默认即可）
Size：大小（一般默认即可）
Carve：切割，不勾选时最省性能；勾选后烘焙的导航网格会动态变化，比如运行时，墙体阻挡，则导航网格与墙体对面导航网格断开连接；墙体移开，则导航网格重新相连
Move Threshold（移动阈值，表示墙体至少移动多少距离才再次切割）
Time To Stationar（静止时间，运行时墙体在移动时不会切割，但是墙体静止后才会切割，且必须静止达到一定的时间）
Carve Only Statio（仅在静止时切割，勾选后上一个功能才有意义）

4、回到角色的Nav Mesh Agent组件，点击Agent Type的Open Agent Settings，在角色代理面板的Agents部分：
Generated Off Mesh Links	生成分离网格链接
Drop Height			掉落/跳跃高度
Jump Distance			跳跃距离

可是设置了跳跃高度，发现导航网格仍然无法从平台“跳下”
设置了跳跃距离，发现导航网格也无法从一个平台“跳到”另一个平台上面

5、给要可以跳跃的平台添加NavMeshModifier组件，勾选Override Generate L，再勾选Generate Links，再次烘焙，导航网格就可以从平台上“跳下”了，也可以从平台“跳到”另一个平台了



四、自定义网格链接——Off Mesh Link组件
比如选择两个点位，当物体移动到一个点位后会跳跃到另一个点位上

1、创建两个正方体，拉伸为两个薄板，充当点位，选中其中一个点位，添加Off Mesh Link组件
2、该组件各个功能（由上至下）：
Start：起始，将第一个点位拖动到这里
End：结束，将第二个点位拖动到这里
Cost Override：成本覆盖
Bidirectional：双向，勾选后可以来回传送
Activated：已激活，勾选后才生效
Auto Update Position：自动更新位置，勾选后，运行时移动点位，导航网格也会跟着点位移动
Navigation Area：导航区域



五、导航区域
1、点开Inspector选项旁边的Navigation(Obsolete)选项，再点击Areas，出现的控制面板即为导航区域，每个区域有对应的颜色，名称和花费

2、花费：比如导航区域中地面花费为1，水域花费为5，那么地面行走所花费的体力比水域少，因此导航也是靠路程和花费综合计算最短、最低成本的最优路线

3、新建一个立方体，拉伸为一个长条状充当河流，为其添加NavMeshModifier组件，勾选组件的Override Area并且在Area Type选项选择Water；同时在Navigation(Obsolete)面板的Areas区域，选则一个空区域（比如User 3），为其命名为Water并且设置花费为5

4、运行后发现角色要导航到“河流”对岸时有时会绕远路

***【Unity常用Ui】

一、画布
1、在Hierarchy区域右键，点击UI，再点击Canvas，创建一块画布

2、并且发现创建Canvas后系统会自动帮我们创建一个EventSystem（事件系统）

3、Canvas比例就是游戏界面的窗口比例，无法直接修改Canvas比例

4、点开Canvas，在控制面板中有个Canvas组件，该部分各个选项由上至下：
Render Mode：渲染模式
Pixel Perfect：像素完美
Sort Order：排序次序
Target Display：目标显示
Additional Shader CI：附加着色器通道
Vertex Color Always

5、Render Mode：渲染模式
该选项共有三个选项：
Screen Space-Overlay（屏幕空间·覆盖）：无需摄像机渲染，UI界面始终在最上层，不会被其它场景物体遮挡
Screen Space-Camera（屏幕空间·摄像机）：需要摄像机渲染，UI界面永远面向摄像机
World Space（世界空间）：需要摄像机渲染，但是整个画布可以旋转

6、Canvas Scaler组件
该组件的UI Scale Mode部分，选择Scale With Screen Size选项，在下方Reference Resolution可以调节分辨率，调节后UI界面会随屏幕大小自适应，始终保持此分辨率大小



二、Image 图像
1、右键Canvas，点击UI，再点击Image

2、点开Image，其各功能由上至下依次为：
Source Image：源图像
Color：颜色
Material：材质
Raycast Target：光线投射目标
Raycast Padding：射线投射填充
Maskable：可遮盖
Image Type：图像类型
Fill Center：填补中心
Pixels Per Unit Multiplier：保持长宽比

3、每个UI都有一个锚点（Anchors），图像的位置都是相对于锚点的

4、锚点由四个三角形构成，拉开这四个三角形，Anchors部分的Min坐标表示左下角坐标，Max坐标表示右下角坐标；同时图像的Pos X、Pos Y、Width和Height分别变为Left、Top、Right、Bottom，表示图像到锚点上下左右的距离；如此以来，UI界面在不同分辨率屏幕上时，四个锚点也会适配的拉伸，而图像距离锚点上下左右距离不变，因此图像也会对应拉伸，从而在不同分辨率屏幕上会有清晰的UI

5、每个图像的位置、旋转和缩放都是在其轴心基础上进行的

3、Button 按钮
新版按钮与旧版按钮几乎完全相同，唯一的区别是新版旧版按钮创建后都会包含一个子物体（文本），旧按钮包含的是旧Text，新按钮包含的是新Text

七、滚动条与滚动视图
1、右键Canvas--->UI--->Slider，创建一个滑动条

3、滑动条本质就是Slider对象的Slider组件的Value（Float类型）

九、常用的UI组件
1、Mask组件
正常创建两个Image图像，其中一个为父物体，子物体在父物体之中的部分，可以正常显示，超出父物体的部分也可以正常显示；给父物体添加Mask组件后，子物体超出父物体的部分会被遮罩

2、Content Size Fitter组件（文本框自适应组件）
比如创建一个文本框，输入了很多文本，超出文本框的无法显示；给文本框添加此组件后，该组件有两个功能：
Horizontal Fit：水平自适应，选择Preferred Size，文本框会自适应调节水平宽度
Vertical Fit：垂直自适应，选择Preferred Size，文本框会自适应调节垂直宽度

3、Vertical Layout Group组件（垂直布局组件）
创建一个面板，面板中要从上至下排列多个控件，单靠鼠标拖动不精确，给面板添加该组件后可以精准调节各个控件的垂直排布，其各功能：
Padding：填充，点开来有Left、Right、Top、Bottom四个选项，每个选项修改对应与面板的间距
Spacing：间距，控制子控件垂直间距
Child Alignment：子级对齐，选择对齐方式，如左上对齐，右下对齐之类，中间对齐的
Reverse Arrangemer：反向排列
Control Child Size：控制子对象大小，勾选Width后，子控件宽度与面板始终保持一致
Use Child Scale：使用子级缩放
Child Force Expand：子力扩展

相应的也有
水平布局组件（Horizontal Layout Group），界面与垂直布局组件相同

4、Grid Layout Group（网格布局组件）
Padding：填充，与上述相同
Cell Size：单元格大小
Spacing：间距
Start Corner：起始角落
Start Axis：启动轴
Child Alignment：子级对齐
Constraint：约束

***【SQL基础语法】

一、SQL语句通用语法
1、SQL语句可以单行或多行书写，以分号结尾。
2、SQL语句可以使用空格/缩进来增强语句的可读性。
3、MySQL数据库的SQL语句不区分大小写，关键字建议使用大写。
4、注释：单行注释：-- 注释内容 或 # 注释内容(MySQL特有)
多行注释：/* 注释内容 */

二、SQL分类
分类	全称	说明
DDL	Data Definition Language	数据定义语言，用来定义数据库对象 (数据库，表，字段)
DML	Data Manipulation Language	数据操作语言，用来对数据库表中的数据进行增删改
DQL	Data Query Language	数据查询语言，用来查询数据库中表的记录
DCL	Data Control Language	数据控制语言，用来创建数据库用户、控制数据库的访问权限



三、DDL
1、增删改查基本操作
查询：
查询所有数据库：SHOW DATABASES
查询当前数据库：SELECT DATABASE();

创建：CREATE DATABASE [ IF NOT EXISTS ] 数据库名 [ DEFAULT CHARSET 字符集 ] [ COLLATE 排序规则];

删除：DROP DATABASE [ IF EXISTS ] 数据库名;

使用：USE 数据库名;

2、表操作
表操作-查询：
查询当前数据库所有表：SHOW TABLES;
查询表结构:DESC表名;
查询指定表的建表语句：SHOW CREATE TABLE表名;


表操作-创建：
CREATE TABLE 表名(
    字段1 字段1类型 [ COMMENT 字段1注释 ],
    字段2 字段2类型 [ COMMENT 字段2注释 ],
    字段3 字段3类型 [ COMMENT 字段3注释 ],
    ……
    字段n 字段n类型 [COMMENT 字段n注释 ]
)[ COMMENT 表注释 ];

表操作-修改
添加字段：ALTER TABLE表名ADD字段名 类型（长度）[COMMENT注释][约束];

修改字段：
修改数据类型：
ALTER TABLE表名MODIFY字段名 新数据类型(长度);

修改字段名和字段类型：
ALTER TABLE表名CHANGE旧字段名 类型(长度)[COMMENT注释][约束]

修改表名：
ALTER TABLE表名RENAME TO新表名;

表操作-删除
删除字段：ALTER TABLE表名DROP字段名;
删除表：DROP TABLE[IF EXISTS]表名
删除指定表并重新创建该表：TRUNCATE TABLE表名;
注意：删除表时，表中数据也会全部删除

四、DML
作用：对数据库中表的数据记录进行增删改查操作
1、添加数据
给指定字段添加数据：
INSERT INTO表名(字段名1,字段名2,...)VALUES(值1,值2,...);

给全部字段添加数据：
INSERT INTO表名VALUES(值1,值2,...);

批量添加数据：
INSERT INTO表名(字段名1,字段名2,...)VALUES(值1,值2,...),(值1,值2,...),(值1,值2,...);
INSERT INTO表名VALUES(值1,值2,...),(值1,值2,...),(值1,值2,...);

注意：①插入数据时，指定的字段顺序需要与值的顺序是一一对应的。② 字符串和日期型数据应该包含在引号中。③插入的数据大小，应该在字段的规定范围内。
2、修改数据
UPDATE表名SET字段名1=值1,字段名2=值2,...[WHERE条件];
注意：修改语句的条件可以有，也可以没有，如果没有条件，则会修改整张表的所有数据


3、删除数据
DELETE FROM表名[WHERE条件];
注意：DELETE语句的条件可以有，也可以没有，如果没有条件，则会删除整张表所有数据
DELETE语句不能删除某一个字段的值(可以使用UPDATE)



五、DQL
1、基本查询
查询多个字段：
SELECT字段1,字段2,字段3...FROM表名;
SELECT * FROM表名;

设置别名（一般为非必须操作）：
SELECT字段1[AS别名1],字段2[AS别名2]...FROM表名;

去除重复记录（即去重查询）：
SELECT DISTINCT字段列表 FROM表名;

2、条件查询（where）
语法：SELECT字段列表FROM表名WHERE条件列表;（字段列表可以为“*”，表示查询所有字段列表）
条件：
比较运算符	功能
>	大于
>=	大于等于
<	小于
<=	小于等于
=	等于
<> 或！=	不等于
BETWEEN ... AND ...	在某个范围之内 (含最小、最大值)
IN(...)	在 in 之后的列表中的值，多选一
LIKE 占位符	模糊匹配 (‘_’匹配单个字符，‘%’ 匹配任意个字符)
IS NULL	是 NULL


逻辑运算符	功能
AND 或 &&	并且 (多个条件同时成立)
OR 或	或者（多个条件任意成立）
NOT 或！	非，不是



3、聚合函数（count,max,min,avg,sum）
作用：将一列数据作为一个整体，进行纵向计算

功能：
count：统计字段的数量
max：最大值
min：最小值
avg：平均值
sum：求和

语法：SELECT聚合函数(字段列表)FROM表名;

4、分组查询（group by）
语法：SLECT字段列表FROM表名[WHERE条件]GROUP BY分组字段名[HAVING分组后过滤条件];


Where与having区别：
执行时机不同：where 是分组之前进行过滤，不满足 where 条件，不参与分组；而 having 是分组之后对结果进行过滤。
判断条件不同：where 不能对聚合函数进行判断，而 having 可以。

注意：执行顺序: where > 聚合函数 > having。
分组之后，查询的字段一般为聚合函数和分组字段，查询其他字段无任何意义。

5、排序查询（order by）
语法：SELECT字段列表FROM表名ORDER BY字段1排序方式1 ,字段2排序方式 2;

排序方式：
ASC：升序（默认值）
DESC：降序

注意：如果是多字段排序，当第一个字段值相同时，才会根据第二个字段进行排序

6、分页查询（limit）
语法：SELECT字段列表FROM表名LIMIT起始索引,查询记录数;

注意：起始索引从 0 开始，起始索引 =（查询页码 - 1）* 每页显示记录数。
分页查询是数据库的方言，不同的数据库有不同的实现，MySQL 中是 LIMIT。
如果查询的是第一页数据，起始索引可以省略，直接简写为 limit 10。

7、执行顺序
编写顺序：
SELECT
    字段列表
FROM
    表名列表
WHERE
    条件列表
GROUP BY
    分组字段列表
HAVING
    分组后条件列表
ORDER BY
    排序字段列表
LIMIT
    分页参数




执行顺序：

    分组字段列表
HAVING
    分组后条件列表

    字段列表

    分页参数
