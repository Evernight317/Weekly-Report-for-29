本周先补完了Git部分课程
 
1. 基础本地Git命令
 
-  git init ：初始化本地Git仓库，生成隐藏的.git文件夹，开启版本管理

-  git add 文件名 ：将指定文件加入暂存区； git add . ：将当前目录下所有变更加入暂存区

-  git commit -m "提交说明" ：把暂存区内容提交到本地仓库，生成版本记录，提交信息要清晰描述改动内容

-  git status ：查看工作区、暂存区当前状态，查看哪些文件修改、未暂存

-  git log ：查看本地仓库提交历史记录，查看每一次提交的版本信息
 
2. 分支操作
 
-  git branch 分支名 ：创建新分支

-  git checkout 分支名 ：切换到指定分支

-  git checkout -b 分支名 ：创建并直接切换到新分支

-  git merge 分支名 ：将指定分支合并到当前所在分支，完成分支代码合并

-  git branch -d 分支名 ：删除本地已经合并完成的分支
 
3. 远程仓库相关
 
-  git clone 远程仓库地址 ：把远程仓库完整克隆到本地，自动建立本地与远程的关联

-  git remote -v ：查看本地关联的远程仓库地址
 
MySQL数据库基础部分复习包括：
 
1. SQL分类复习
 
- DML（数据操作语言）：增删改， insert 、 update 、 delete ，操作表里面的数据

- DQL（数据查询语言）：查询， select ，实现单表、多表数据检索

- DCL（数据控制语言）：权限管理，用户授权、回收权限
 
2. 数据库约束
复习主键约束primary key、非空约束not null、唯一约束unique、外键约束foreign key，理解约束作用：保证表数据完整性。

3. 多表查询
复习内连接、左连接、右连接，掌握多表关联查询写法，处理多张表之间的数据关联。

4. 事务
回顾事务四大特性ACID；事务开启 begin、提交 commit 、回滚 rollback ；理解事务的隔离级别，保证多条SQL操作的原子性，避免数据错乱。

5. 函数
复习MySQL内置函数，字符串函数、数值函数、日期函数，使用函数对查询结果做处理。
