\# 第5-6周后端开发学习周报



\## 一、本周学习内容



1\. 了解 Web 开发整体流程，明确前端、后端和数据库之间的关系。

2\. 学习 HTTP 协议与 Web 请求，掌握前后端数据交互的基本过程。

3\. 学习 JavaWeb 三层架构，理解表现层、业务层和数据访问层的职责。

4\. 学习 Maven 项目管理，包括项目创建、依赖引入和项目构建。

5\. 完成 Spring Boot 项目搭建，熟悉项目结构、配置文件和运行流程。

6\. 学习在 Spring Boot 中整合 MyBatis 和 MySQL，完成数据库连接配置。

7\. 掌握 MyBatis 的基本增删改查操作，练习注解和 XML 两种实现方式。

8\. 复习 MySQL 基础语法，能够独立编写简单的查询、新增、修改和删除 SQL。

9\. 简单了解 MyBatis 动态 SQL 和 Lombok 的基本用法。

10\. 配套学习 JavaScript、Vue、AJAX 和 Axios，了解页面开发及前后端异步交互方式。



\## 二、实践内容



\- 搭建并运行 Spring Boot 项目。

\- 使用 Maven 引入项目所需依赖。

\- 配置 MyBatis 和 MySQL 数据库连接。

\- 使用注解及 XML 编写增删改查功能。

\- 结合课程案例完成管理系统后端代码练习。

\- 整理项目运行过程及相关截图。



\## 三、学习总结



通过本阶段学习，初步掌握了 Spring Boot 后端项目的搭建流程，能够使用 Maven 管理依赖，并使用 MyBatis 操作 MySQL 数据库。同时了解了 HTTP、三层架构和前后端交互方式，为后续完成更完整的 JavaWeb 项目打下了基础。（作业我会补交一下）
