### Nginx&负载均衡

前端请求地址 后端端口地址；

nginx反向代理，就是将前端发送的动态请求由nginx转发到后端服务器；

#### Nginx优势

- 提高访问速度。nginx可以将请求端口缓存在本地；
- 进行负载均衡。直连的话请求一个确定端口/一个固定服务器，nginx可以视负载分发；
- 保证后端服务安全；

#### 配置-反向代理

`nginx.conf`配置

动态请求路径还会追加到路径后，拼接成完整转发路径

```Shell
server{
	listen 80;
    server_name localhost;
  
    location /api/ {
    	#反向代理
    	proxy_pass http://localhost:8080/admin/;
    }

}
```

#### 配置-负载均衡

```Shell
upstream webservers{
	server 192.168.100.128:8080;
	server 192.168.100.129:8080;
}

server{
	listen 80;
    server_name localhost;
    location /api/ {
    	#负载均衡
		proxy_pass http://webservers/admin/;
    }
  
}
```

| nginx负载均衡策略<br />名称 |                                                        |
| --------------------------- | ------------------------------------------------------ |
| 轮询                        | 默认方式                                               |
| weight                      | 权重方式，默认为1，权重越高，被分配的客户端请求就越多  |
| ip_hash                     | 依据ip分配方式，这样每个访客可以固定访问一个后端服务   |
| least_conn                  | 依据最少连接方式，把请求优先分配给连接数少的后端服务   |
| url_hash                    | 依据urI分配方式，这样相同的urI会被分配到同一个后端服务 |
| fair                        | 依据响应时间方式，响应时间短的服务将会被优先分配       |

## 七、接口文档

定义接口-前后端并行开发-联调-提测；

Yapi是设计阶段使用的工具，管理和维护接口；Swagger在开发阶段使用的框架，帮助后端开发人员做后端的接口测试

### Swagger

后端生成接口文档并测试；

只需要按照它的规范去定义接口及接口相关的信息，就可以做到生成接口文档，以及在线接口调试页面；

### 静态资源映射

knife4j在jar包中，直接访问会被拦截，并且要拦截器增加放行规则；

### Knife4j

JavaMVC框架集成Swagger生成Api文档的增强解决方案；

1. maven导入knife4j；
2. 配置类中加入相关配置；
3. 设置静态资源映射，否则接口文档页面无法访问；

- 没有设置静态资源映射的话，会将`/doc.html`认为是一个动态的请求，但此时没有map的controller方法故报错；

### Swagger-注解

注解加入后，可以显示在接口文档上；

|                                     |                                                        |

| `@ApiOperation(value = "说明")`   | 用在方法上，例如controller的方法，说明方法的用途、作用 |
