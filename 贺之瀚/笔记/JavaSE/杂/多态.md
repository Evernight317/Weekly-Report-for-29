# 多态&接口

多态有两种：

1. 编译时多态（静态多态），其实就是方法重载，略；
2. **运行时多态** （动态多态），这个是主流，而且非常核心；

## 运行多态

很多时候的体现形式都是**接口+不同的实现类** ，这个也是解耦（低耦合）、SpringBoot框架中IOC/DI的基础；

```Java
// interface 	implements
Animal A = new Dog();
```

（怎么理解编译看左边，运行看右边）

- 接口不能被实例化：这个指的是接口不能创建相应的对象；
- 接口右边的一般都是实现类，从接口角度上出发（特殊继承），本质都是属于Animal的，也就是所谓的向上转型；

我这样写是可以确定Dog实现了Animal这个接口的，因此这个就是所谓的小类型转成大类型（**向上转型**），这样当然是合法的；然后从接口角度出发，既然Dog实现了Animal接口，由于接口的特性（一种特殊的继承），所以说





## 接口

本质上就是一种很特殊的继承，但是在这种很特殊的基础之上发展出了多态；

- 接口只是定义了行为（或者说一些行为的规范），但是具体的操作是不关注的，因此就有了多态；
