# File&IO流-File

File代表文本/文件，IO流读写数据；

文件：较长时间保存数据的存储方式；

程序运行时数据在内存中，而文件在硬盘中；

`File`类就是代表文件类(`java.io`)，File类对象代表当前OS的文件（夹）；

注意：File类只能 **对文件本身进行操作** ，不能读写文件里面存储的数据；

IO流：用于读写数据（读写文件/网络中数据）

---

## 一、File

### 1.构造器

| 构造器                                       |                                                |                                                  |
| -------------------------------------------- | ---------------------------------------------- | ------------------------------------------------ |
| `public File(String pathname)`             | 根据文件路径创建文件对象                       | 即用一个File对象代表路径对应的实体文件或者文件夹 |
| `public File(String parent, String child)` | 根据父路径和子路径名字创建文件对象             |                                                  |
| `public File(File parent， String child)`  | 根据父路径对应文件对象和子路径名字创建文件对象 |                                                  |

File对象指向文件夹时，`File.length()`获取的是 **文件夹本身大小** ，而不是文件夹所有内容的大小，文件夹本身仅记录内部文件的基本信息，系统的文件夹大小则包括文件夹内的内容；

File对象也可以指向不存在的文件路径，可以用`exists`方法替代；

#### 路径分隔符

1. 斜杠`/`；
2. 反斜杠，注意写**转义字符 `\\`；**
3. 采用File的常量`File.separator`。如`"D:"+File.separator+"a.txt"`，该常量的对应的分隔符与系统一致，若系统默认`/`则为`/`，若为`\\`则为`\\`

#### 绝对路径&相对路径

假设现在有一个完整的工程文件，在自己电脑上路径为

`D:/javaprogram/src`，实际工程文件全部位于src文件夹

**绝对路径** ：带有盘符，是一个完整的路径，即 `D:/javaprogram/src/a.txt`；

**相对路径** ：不带有盘符，实际使用时 *默认直接到当前工程下的目录寻找文件* ，一般写成 `模块名/a.txt`的形式，即`src/a.txt`，也就是说，相对路径从工作目录开始；

### 2.常用方法-判断文件类型、获取文件信息

|                                     |                                                                                                                      |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `public boolean exists()`         | 判断File对象对应的文件路径是否存在，存在返回true                                                                     |
| `public boolean isFile()`         | 判断File对象指代的是否是文件，是文件返回true                                                                         |
| `public boolean isDirectory()`    | 判断File对象指代的是否是文件夹，是文件夹返回true                                                                     |
| `public String getName()`         | 获取文件的名称（包含后缀，即完整名称）                                                                               |
| `public long length()`            | 获取文件的大小，返回**字节** 个数；<br />只能对**文件** 使用！！！在win系统下对文件夹使用默认返回0！！！ |
| `public long lastModified()`      | 获取文件的最后修改时间（返回值为ms形式，可以用SDF格式化）                                                            |
| `public String getPath()`         | 获取创建File对象时，使用的路径                                                                                       |
| `public String getAbsolutePath()` | 获取绝对路径，（即使创建对象时使用相对路径，也会返回绝对路径）                                                       |

`public long length()` 只能对 **文件** 使用，在win系统下对文件夹使用默认返回0！！！

### 3.常用方法-创建删除文件

|                                    |                                                  |                                                                                                                    |
| ---------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| `public boolean createNewFile()` | 创建一个新文件（文件内容为空），创建成功返回true | 如果文件已经存在，则会创建失败返回false                                                                            |
| `public boolean mkdir()`         | 创建文件夹，创建成功返回true                     | 只能创建**一级** 文件夹，创建多级文件夹会失败并返回false                                                     |
| `public boolean mkdirs()`        | 创建文件夹，创建成功返回true                     | 可以创建**多级** 文件夹                                                                                      |
| `public boolean delete()`        | 删除文件，或者空文件夹                           | delete删除的文件*不会进入回收站* ，而是直接粉碎；<br />不能删除**非空文件夹** ，试图删除会失败并返回false |

### 4.常用方法-遍历文件夹

这两个方法都只能遍历一级文件；

|                               |                                                                     |
| ----------------------------- | ------------------------------------------------------------------- |
| `public String[] list()`    | 获取当前目录下所有的**一级文件名称** 到一个字符串数组中去返回 |
| `public File[] ListFiles()` | 获取当前目录下所有的**一级文件对象** 到一个File数组中去返回  |

#### 使用ListFiles的注意点

- 当主调是**文件** ，或者**路径不存在** 时，返回`null`；
- 当主调是**空文件夹** 时，返回一个长度为0的数组，这个可以用来判断文件夹是否**清空** ！！！；
- 当主调是一个 **有内容的文件夹** 时，将里面所有一级文件和文件夹的路径放在File数组中返回；
- 当主调是一个文件夹，且里面有 **隐藏文件** 时，将里面所有文件和文件夹的路径放在File数组中返回，*包含隐藏文件* ；
- 当主调是一个文件夹，但是 **没有权限** 访问该文件夹时，返回`null`

### 5.文件搜索&递归

File提供的方法只能获取一级文件对象，所以要在多级文件夹中找一个特定文件显然需要使用递归；

#### 思路

1、先获取初始File对象的所有一级文件对象

2、如果是文件，则直接判断；如果是文件夹，则进入并重复上述过程；

3、边界条件很显然：获得的一级对象是文件；

不过这种方法很明显是一个不剪枝的DFS，当对应目录文件是海量小文件时时间复杂度很夸张，只能小目录或者少数大文件目录使用；
