# 正则

由特定字符组成的规则

应用：用来校验数据格式是否合法、在一段文本中查找满足要求的内容；

String中提供了匹配正则表达式的方法判断字符串是否匹配正则表达式，匹配返回`true`，不匹配返回`false`：`public boolean matches（String regex)`

## 规则

`[]` 只可用于匹配单个字符

| 字符类（只匹配单个字符） |                                                |
| ------------------------ | ---------------------------------------------- |
| `[аbc]`               | 只能是a，b，或c                                |
| `[^abc]`               | 除了a，b，c之外的任何字符                      |
| `[а-zA-Z]`            | a到zA到z，包括（范围）                         |
| `[a-d[m-p]]`           | a到d，或m到p                                   |
| `[a-z&&[def]]`         | d,e，或f（交集）（即属于a-z，并且属于def集合） |
| `[а-z&&[^bc]]`        | a到z，除了b和c（等同于[ad-z]）                 |
| `[a-z&&[^m-p]]`        | a到z，除了m到p（等同于[a-1q-z]）               |

实际使用时，`\`要写成转义字符`\\`！

只能匹配单个字符，如 `"1".matches ("\\d")` 为true，`"1",matches ("\\d")`为false；

| 预定义字符（只匹配单个字符） |                         |
| ---------------------------- | ----------------------- |
| `.`                        | 任何字符                |
| `\d`                       | 0-9的一个数字`[0-9]`  |
| `\D`                       | 非数字字符`[^0-9]`    |
| `\s`                       | 一个空白字符            |
| `\S`                       | 非空白字符`[^\s]`     |
| `\w`                       | `[a-zA-Z_0-9]`        |
| `\W`                       | 一个非单词字符`[^\w]` |


| 数量词      |                                     |
| ----------- | ----------------------------------- |
| `X?`      | X，至多一次（0次或1次）             |
| `X*`      | X，零次或多次                       |
| `X+`      | X，至少一次                         |
| `x {n}`   | X，正好n次                          |
| `x {n, }` | X，至少n次                          |
| `x {n,m}` | X，$[n,m]$ 次（至少n次，至多m次） |

~~正则表达式无法匹配中文！因此一旦有中文就会影响匹配结果（false）~~
