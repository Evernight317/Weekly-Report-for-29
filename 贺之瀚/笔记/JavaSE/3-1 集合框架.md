# 集合

主要分为两种：`Collection` 代表的 **单列集合** 和 `Map`代表的 **双列集合** ；

| 单列集合           | 双列集合                                                    |
| ------------------ | ----------------------------------------------------------- |
| 每个元素只有一个值 | 每个元素有两个值，<br />成为 **键值对 key-value** ； |

## 单列集合

`Collection<E>` 为泛型接口，包括 `Lise<E>` 和 `set<E>` 两大类接口

| `List<E>`的实现类                            | `Set<E>`的实现类                              |
| ---------------------------------------------- | ----------------------------------------------- |
| 包括`ArrayList<E>` 和<br />`LinkedList<E>` | 包括`HashSet <E>` 和<br />`TreesSet<E>`     |
|                                                | `HashSet<E>` 又包括<br />`LinkedHashSet<E>` |

| col1                 | 特点                                                                                          | 每个实现类特点                                                                                                                                  |
| -------------------- | --------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `List<E>` 系列集合 | 添加的元素**有序、可重复、有索引** ；<br />此处有序指的是进入集合顺序和获取数据顺序一致 |                                                                                                                                                 |
| `Set<E>` 系列集合  | 添加的元素**无序、不重复、无索引** ；                                                   | `HashSet` 一致；<br /> `LinkedHashSet` **有序** 、不重复、无索引；<br />`TreeSet` **按照大小默认升序排序** 、不重复、无索引； |

### 遍历方式

采用for需要获得索引，但是只有List支持索引；

#### 迭代器

迭代器要注意不能超出范围，否则会异常

|                            |                                                                  |
| -------------------------- | ---------------------------------------------------------------- |
| `Iterator<E> iterator()` | 返回集合中的迭代器对象，该迭代器对象默认指向当前集合的第一个元素 |
| `boolean hasNext()`      | 询问当前位置是否有元索存在，存在返回true，不存在返回false        |
| `E next()`               | 获取当前位置的元素，并同时将选代器对象指向下一个元素处           |

```Java
Iterator<String> it = c.iterator();
while (it.hasNext()) {
  	// 每次取数据都要事先判断是否非空
	String ele = it.next();
    System.out.println(ele);
}
```

```Java
for (元素的数据类型 变量名：数组或者集合) {
 	 
}
Collection<String> c = newArrayList<>();
for (String s : c) {
  
}
```

#### Lambda(>JDK8)

|                                                      |                    |
| ---------------------------------------------------- | ------------------ |
| `default void forEach(Consumer<? super T> action)` | 结合Lambda遍历集合 |

```Java
// 完整写法，匿名内部类
c.forEach(new Consumer<String>() {
    @Override
    public void accept(String s) {
        // TODO Auto-generated method stub
        System.out.println(s);
    }
});

// Lambda简化
c.forEach(s -> System.out.println(s));
// 实例方法引用
// out是一个对象，println则是实例方法
c.forEach(System.out::println);
```

#### 遍历对象

集合存储的是元素对象的 **地址** ；直接遍历则会输出集合地址；

直接遍历集合内容的话重写`toString`方法即可；

## 三、ArrayList实现类

`ArrayList` 和 `LinkedList` 底层的 **数据结构不同** ，对应应用场景也不同；

### 底层原理

`ArrayList` 基于数组实现；

- **查询快** ，$O(1)$（根据索引查询速度快，起始地址偏移计算即可）；
- **增删慢** ，$O(N)$；因为都涉及到整体数据移动

1、使用无参构造器时，会在底层创建一个默认长度为 **0** 的数组；

2、添加第一个元素时，底层会创建一个新的长度为 **10** 的数组；如果是1的情况的话，相当于就是扩容成10；

3、存满时，扩容 **1.5** 倍，即第11个数存入时，扩容成15；（这里的操作好像是先创建新的数组，再将数据迁移）

4、如果一次添加多个元素，1.5倍还放不下，则新创建数组的长度以实际为准。比如使用`addAll` 时，原数组已经有10个数，又要加11个数，则会新创建21个数的数组；

因此适合数据量小或者根据索引查询数据的情况；当数据量大且需要频繁增删时，时间开销会很大。

## 四、LinkedList实现类

### 底层原理

基于 **双向链表** 实现；

查询慢，增删快，对 **首尾元素的操作速度极快** （增删查改）；

`LinkedList` 增加了首尾特有的操作方法

|                                                                    |                                                  |
| ------------------------------------------------------------------ | ------------------------------------------------ |
| `public void addFirst(E e)`<br /> `public void addLast(E e)`  | 在列表开头插入指定的元素<br />在列表末尾追加元素 |
| `public E getFirst()`<br /> `public E getLast()`              | 返回首/尾元素                                    |
| `public E removeFirst()` <br />`public E removeLast()`        | 删除并返回 首/尾元素                             |

`LinkedList` 可以用来实现队列和栈，对于栈，又可以使用`push` 和`pop` 方法，底层是调用 `addFirst` 和 `removeFirst` 方法；注意这里是 **把first视作队尾和栈顶** ；
