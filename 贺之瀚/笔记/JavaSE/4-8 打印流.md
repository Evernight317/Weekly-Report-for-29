# 打印流

|                 |                    |
| --------------- | ------------------ |
| `PrintStream` | 字节输出流的实现类 |
| `PrintWriter` | 字符输出流的实现类 |

打印流可以实现更方便、更高效的打印数据出去，能实现打印啥出去就是啥出去；打印流自带缓冲池；

常用的`System.out.println`中，`System.out`对象就是打印流的实例；

---

## PrintStream

| 构造器                                                                       |                                              |
| ---------------------------------------------------------------------------- | -------------------------------------------- |
| `public Printstream(OutputStream/File/String)`                             | 打印流直接通向*字节输出流/文件/文件路径* ； |
| `public PrintStream(String fileName, Charset charset)`                     | 可以指定写出去的字符编码                     |
| `public PrintStream(OutputStream out,boolean autoFlush)`                   | 可以指定实现自动刷新                         |
| `public PrintStream(OutputStream out, boolean autoFlush, String encoding)` | 可以指定实现自动刷新，并可指定字符的编码     |

方法

|                                                |                                      |  |
| ---------------------------------------------- | ------------------------------------ | - |
| `public void println(Xxx xx)`                | 打印任意类型的数据出去，可以自带换行 |  |
| `public void print(Xxx xx)`                  | 同上，但                             |  |
| `public void write(int/byte[]/一部分byte[])` | 可以支持写 **字节** 数据出去        |  |

由于是PrintStream的实现类，也支持Write方法，也就是说，写97输出为`'a'`

## 二、PrintWriter

|                                                                             |                                          |                      |
| --------------------------------------------------------------------------- | ---------------------------------------- | -------------------- |
| `public PrintWriter(OutputStream/Writer/File/String)`                     | 打印流直接通向字节输出流/文件/文件路径   | 还可以通向字符输出流 |
| `publicPrintwriter(String fileName,Charset charset)`                      | 可以指定写出去的字符编码                 |                      |
| `public PrintWriter(OutputStream out/Writer,boolean autoFlush)`           | 可以指定实现自动刷新                     |                      |
| `public Printwriter(outputstream out, boolean autoFlush,String encoding)` | 可以指定实现自动刷新，并可指定字符的编码 |                      |

方法

|                                             |                                   |                               |
| ------------------------------------------- | --------------------------------- | ----------------------------- |
| `public void println(Xxx xx)`             | 打印任意类型的数据出去            | 主要用这个，不换行用`print` |
| `public void write(int/string/char[]/..)` | 可以支持写**字符** 数据出去 |                               |

## 注意点

打印流作为高级流，*无法直接变为追加管道* ，需要先包装低级流才能实现追加；

## 四、输出语句重定向

### System.out

源码如下

```Java
public static final PrintStream out = null;
```

也就是说`System.out`变量是一个`PrintStream`*引用变量* ；同时，System类在加载时就会静态初始化，`Sytem.out`也会被指向一个初始化的打印流对象，这个对象*默认是通向标准输出设备，一般是console* ；

### 重定向-> System.out.setOut()

比如说在服务器运行时，~就没有console了~ ，这种情况一般要重定向，从而改变打印流的数据通道通向；

|                                    |                                        |
| ---------------------------------- | -------------------------------------- |
| `System.setOut(PrintStream out)` | 把默认打印流对象改为自定义的打印流对象 |

```Java
PrintStream ps = new PrintStream("目标写入文件地址");
System.setOut(ps)；
```

这样就可以使打印流对象打印至指定文件；
