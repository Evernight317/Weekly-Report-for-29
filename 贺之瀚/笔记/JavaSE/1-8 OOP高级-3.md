# OOP高级-3

## 一、内部类

四种：成员内部类，静态内部类，局部内部类， **匿名内部类**；

### 成员内部类

创建方式：先创建外部类，再创建内部类，即 `Outer.Inner in =new Outer().new Inner();`

成员内部类相当于成员方法，可以访问外部类的成员；

| 访问变量 | 无       | this       | 外部类名.this    |
| -------- | -------- | ---------- | ---------------- |
|          | 局部变量 | 内部类成员 | 访问外部类的成员 |

### 静态内部类

创建方式：（和静态成员变量一样可以直接通过类名访问），直接通过外部类名.内部类名创建 如 `Outer.Inner in = new Outer.Inner ();` ；

访问：和静态成员方法类似，可以访问外部类的静态成员，但不能访问实例成员

局部内部类即定义在方法、代码块、构造器的类/接口，一般用的不多；

## 二、匿名内部类

一种特殊的局部内部类（接口），当仅创建一个实例对象时可采用（创建子类对象更方便）；因此，匿名类本质可理解为一个 子对象；

匿名指的是无需对这个类声明名字；格式如下

```Java
new Class/interface (形参) {
  	// 一般为方法重写
}
```

例&原理

编译遇到匿名内部类时，会将把其编译成一个子类，然后立刻创建一个子类对象

```Java
Animal a = new Animal () {
	@override
	public void cry() {
		System.out.println("猫喵喵喵的叫~~~");
    }
}
	a.cry ();
```

#### 常见应用

匿名内部类常作为 **一个参数** 传给方法；比如实际开发中，调用API时，可能对应的形参是一个对象且为接口。对于接口，一般就是传实现类或者匿名内部类，此时往往选择匿名内部类传参；

```Java
public interface animal {
	void swim ();
}
public class Test {
	public static void main(String[] args) {
      	// 采用匿名内部类实现了一个子类对象狗，并作为go函数参数
      	// 但go方法实际上就是把匿名内部类作为形参，因此可以省去，直接将匿名内部类作为go方法形参
		// Swimming s1 = new Swimming(){
		// 	@Override
		// 	public void swim(){
		// 		System.out.println("狗游泳")；
		// 	}
  //       }
		// go(s1);

  
		go (new animal() {
			@Override
			public void swim() {
				System.out.println("猫游泳")；
        	}
    	});
  
    }
  
      public static void go(animal s) {
          System.out.println("let's gooooo");
          s.swim ();
      }
}
```

## 三、枚举

本质：一种特殊类；

```Java
public enum A{
	// 名称
  	X,Y,Z
  	// 类的五大成员
}
```

- 枚举类的第一行只能写名称，这些名称都是常量，并且每个常量记住的都是一个 **枚举类对象** 。
- 枚举类的构造器一定且默认为私有，因此枚举类对外不能创建对象。
- 枚举都是最终类，不可以被继承。
- 枚举类中，从第二行开始，可以定义类的其他各种成员。
- 编译器为枚举类新增了几个方法，并且枚举类都是继承：`java.lang.Enum` 类的，从enum类也会继承到一些方法。

```Java
A[] a = A.valuesO；//拿到全部对象
A a3 = A.valueof("Z");
System.out.println(a3.name());// Z
System.out.println(a3.ordinal())；//索引
```

### 抽象枚举

枚举中有抽象方法，此时无法直接写枚举名称，因为本质上是创建对象，会报错；因此可以构建一个匿名内部类来达到构建对象的目的，并且调用的构造器有参无参皆可~~要手动调用枚举类构造器（有参无参皆可），并重写里面的方法，~~

```Java
public enum B {
	X () {
      	@override
      	public void go () {
  
        }
    }, Y() {
        @override
      	public void go () {
  
        }
    };
  
  	public abstract void go ();
}
```

#### 枚举应用

- 枚举可以用来构造 **单例** 。由于枚举的构造器默认私有，因此只写一个名称即可；

```Java
public enum A {
  	X;
  	// ...
}
```

- （这个其实就和C++的enum差不多，搭配switch使用，限定传入参数范围，超出就会报错）用常量/字面量作信息分类时，无法控制传参是否合规（如男为1即硬编码，或者建Constant包，常量MAN即软编码，女为0）；枚举就可以用来作为信息的标志、分类，常见用途就是搭配switch使用（见对应项目）；

## 四、泛型

这个其实就和C++的模版元编程(弱化版)

需要加上类型定义，即  `<E e,T t...>` ；

java的泛型就是声明时不确定类型，用`E`等大写字母事先占位，但是在使用时填入具体类型；此时由于类型不确定，因此被定义为`Object`，以此能存储任意类型的数据；

#### 泛型类

定义时，参数换成占位符即可；E K T V

泛型可以要求被限定，如`<E extends A>` ，也就是要求填入的类型必须是 **A或A的子类** ；

#### 泛型接口

接口是可以实现对同一数据的多种相同本质操作，当要对多种数据进行相同操作，就可以使用泛型接口；

泛型中也可以被限定，如在定义类型时可以在类型定义时加上限制`<E extends A>`，即要求必须是A的子类

#### 泛型方法

修饰符后加上类型定义；

泛型类的成员方法不是泛型方法，因为没有定义类型变量

#### 通配符&上下限

比如定义泛型方法时，形参是`ArrayList`，而集合本身就是一个泛型类，这时候可以不用再对这个泛型类额外定义；

可以加上 **通配符`?`**  ；

通配符在 **使用泛型** 时可以代表接受一切类型，比如说使用集合时使用通配符，即`ArrayList <?>`；

同样，也可以对通配符做出限制，如 `<? extends A>` 表示接受的必须是A或A的子类，这种就是 **上限** ，即最高是A；

或者也有下限， `<? super A>` 表示必须是A或A的父类，也就是下限，即最低是A；

#### 泛型擦除

泛型是工作在编译阶段的，一旦程序编译成class文件，class文件中就不存在泛型了，这就是泛型擦除；即底层还是Object（这个和C++的模板原理不同，C++的模板是每个对应一份单独的机器码，因此会存在模板膨胀的问题）

#### 泛型支持

泛型不支持基本数据类型，只能支持 **对象类型（引用数据类型）** 。

| `int`     | `float` | `double` |
| ----------- | --------- | ---------- |
| `integer` |           | `Double` |
|             |           |            |
