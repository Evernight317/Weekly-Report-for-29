# IO流

两种分类方式：

| 按流的方向分类 |                        | 按流中最小数据单位分类 |                                         |
| :------------: | ---------------------- | :--------------------: | --------------------------------------- |
|  输入流input  | 负责把数据读到内存中去 |         字节流         | 适用于所有文件，尤其是*文件的拷贝* ； |
|  输出流output  | 负责写数据出去         |         字符流         | 只适用于 **纯文本文件** ；             |

组合得到四种基础流：

| 流         | 对应抽象类       | 对应继承实现类      |
| ---------- | ---------------- | ------------------- |
| 字节输入流 | `Inputstream`  | `FileInputStream` |
| 字节输出流 | `OutputStream` | `FileOutputSteam` |
| 字符输入流 | `Reader`       | `FileReader`      |
| 字符输出流 | `Writer`       | `FileWriter`      |

字节流更适合做 *数据转移* ，字符流更适合*读取文本内容* ；

## 一、FileInputStream

文件字节输入流：以内存为基准，可以把磁盘文件中的数据以字节的形式读入到内存中去；

| 构造器                                      |                                                    |
| ------------------------------------------- | -------------------------------------------------- |
| `public FileInputStream(File file)`       | 创建字节输入流管道，通过File对象的方式与源文件接通 |
| `public FileInputStream(String pathname)` | 创建字节输入流管道，通过文件路径的方式与源文件接通 |


| 方法                               |                                                                                                |
| ---------------------------------- | ---------------------------------------------------------------------------------------------- |
| `public int read()`              | 每次读取**一个字节** 返回，如果发现没有数据可读会返回-1                                  |
| `public int read(byte[] buffer)` | 每次用一个字节数组去读取数据，返回字节数组读取的 **字节个数** ，如果发现没有数据可读会返回-1 |

### read读取一个字节

流使用完成后必须关闭；

```Java
int b;
// 这样是错的！！！
// while(is.read() != -1) {
//   	b = is.read();
//   	System.out.println(b);
// } 
while ((b=is.read()) != -1) {
  	System.out.print((char) b);
}
```

这个读取方式的问题：1、效率低，每次调用read都涉及到一次与硬件的交互；

2、读取汉字一定会乱码；

### read读取多个字节

注意点：重复使用buffer数组的话，是直接对原来的内容进行**覆盖 ** ；当一次读取的字节数<buffer长度时，*末尾的元素不会被覆盖改变* ，此时转换为String时要注意 *控制长度为实际读取字节数* ，可以使用String的构造器`String (byte[], long, long)` 实现

```Java
byte[] buffer = new byte[3];
int len;
while ((len = is.read(buffer)) != -1) {
    // 读取多少取多少！！！
    String rs = new String(buffer,0, len);
    System.out.print(rs);
}
```

效率更高；但仍然无法避免汉字出现乱码，更适合作为文件拷贝使用；

### 读取整个文件

`byte[]`数组是在内存中存储，所以说长度限制为int，而`File.length()` 的返回类型是long，所以需要强制转换；这也限制了这种方法的使用范围，只能对小文件使用，也就是FAT32格式的文件，使用32位记录文件信息；

```Java
File file = new File("File_IO流/IO流/FIS.txt");
long len = file.length();
byte[] buffer = new byte[(int) len];
is.read(buffer);
String rs = new String(buffer);
System.out.println(rs);
```

但是还提供了一个方法`readAllBytes`，可以直接读取整个文件的全部字节到一个byte数组中返回；并且方法内部有校验机制，当文件过大时会抛出异常；

|                                                     |                                                                   |
| --------------------------------------------------- | ----------------------------------------------------------------- |
| `public byte[] readAllBytes() throws IOException` | 直接将当前字节输入流对应的文件对象的字节数据装到一个字节数组返回  |

```Java
byte[] buffer = is.readAllBytes();
String rs = new String (buffer);
System.out.println(rs);
```

## 二、FileOutputStream

以内存为基准，把内存中的数据以字节的形式写出到文件中去；

| 构造器                                                       |                                                                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| `public FileoutputStrean(File file)`                       | 创建字节输出流管道与源文件File对象接通                                                |
| `public FileOutputStream(String filepath)`                 | 创建字节输出流管道与源文件路径接通                                                    |
| `public FileOutputStream(File file, boolean append)`       | 创建字节输出流管道与源文件File对象接通；<br />`append` 控制是覆盖管道还是追加管道； |
| `public FileOutputStream(String filepath, boolean append)` | 创建字节输出流管道与源文件路径接通，可追加数据                                        |

`append` true**追加** 管道，不加参数true则默认**覆盖** 管道，即 *创建文件输出流对象时* ，如果文件已经存在，则会**清空** 文件，而追加则是在文件基础上接着向后写；

| 方法                                                   |                               |
| ------------------------------------------------------ | ----------------------------- |
| `public void write(int a)`                           | 写一个字节出去                |
| `public void write(byte[] buffer)`                   | 写一个字节数组出去            |
| `public void write(byte[] buffer ,int pos ,int len)` | 写一个字节数组的一部分出去。  |
| `public void close() throws IOException`             | 关闭流                        |

`write` 方法形参是int，但传入的数据会发生高位截断，仅保留 **低8位** ；

write采用第一种形式的话，无法写出汉字，UTF-8下汉字是三个字节，会乱码；

### 写出文件

*创建流对象时* ，如果路径对应的文件不存在，则会自动创建一个对应文件；

*创建流对象时* ，如果文件已存在，覆盖管道会 *清空文件内容* ，追加管道则不会；

跨平台能力较好的换行符为`\r\n` ，由于不是一个字节，需要转换成byte数组；

```java
public static void write_1(String path) throws Exception{
    OutputStream os = new FileOutputStream(path);
    os.write(97);
    // 'b'在底层也相当于整数
    os.write('b');
    byte[] bytes = "宝宝你好大".getBytes();
    os.write(bytes);
    os.close();
}
// 采用追加管道的方式
public static void write_2(String path) throws Exception {
    OutputStream os = new FileOutputStream
    ("File_IO流/IO流/FOS.txt",true);
    os.write(104);
    os.write('z');
    os.write('h');
    byte[] bytes = "18cm硬邦邦".getBytes();
    os.write(bytes);
    byte[] enter = "\r\n".getBytes();
    os.write(enter);
}
```

### 文件复制

简单点的思路：直接整个读取为byte数组，然后再整个输出到特定文件实现复制；

也可以设置一个byte数组buffer，假定大小是1024字节即1KB，然后逐次IO；
