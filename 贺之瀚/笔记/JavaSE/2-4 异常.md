# 异常

问题信息被异常类封装后抛出给调用者/上一级（main方法即为JVM虚拟机），然后暂停程序执行并将异常信息打印；

## 异常体系/分类

`Java.lang.Throwable`分为`Error`和`Exception`，其中`Exception` 又分为

`RuntimeException` **运行时异常** 和 **编译异常** ；

`Error` ：代表的系统级别错误（属于严重问题）~~，不是学习重点~~；

`Exception` ：异常，代表的才我们程序可能出现的问题。通常会用 `Exception` 以及它的子类来封装程序出现的问题；

| 运行时异常                                                                | 编译异常                                                                         |
| ------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `RuntimeException` 及其子类，编译阶段不会出现错误提醒，运行时出现的异常 | 编译阶段就会出现错误提醒                                                         |
| 如数组索引越界异常                                                        | 日期解析异常（使用<br />`SimpleDateFormat.parse (String)` 时就会提醒的异常 ） |

## 自定义异常

方法内输出异常的问题：无法向调用者报告异常，不直观？  

通过自定义异常类来自定义异常，注意两种异常的 **父类** 不同；

### 自定义运行时异常

1. 定义一个继承自 `RuntimeException` 的运行时异常类；
2. 重写构造器；
3. 通过 `throw new 异常类 (xxx)` 来创建异常对象并抛出。
   编译阶段不报错，运行时才可能出现；

### 自定义编译时异常

1. 定义一个继承自  `Exception` 类的异常类；
2. 重写构造器；
3. 通过 `throw new 异常类(oxx)` 来创建异常对象并抛出
   编译阶段就报错，红线提醒更明显；

（见项目）

`throw` 关键字的作用：暂停当前方法执行，并将异常结果返回给调用者；

`throws` 关键字的作用：用在 **方法** 上，将方法内部的异常抛出给上一级调用者，使当前一级无红线报错提醒，直到最外层方法采用 `try-catch` 的方式捕获异常；

```Java
// throw
```

异常可以视为方法内部的一种特殊返回值，反馈给上一个底层方法的执行情况；

异常也可以作为问题定位的参考；

## 异常处理&处理方式

分为 **抛出异常**  `throws` 和 **捕获异常**  `try-catch` ；同时对于抛出异常，一般后面跟的异常类直接写 `Exception` ；

```Java
// 抛出异常
方法 throws 异常1，异常2，异常3 {
  	...
}
// 推荐写法
方法 throws Exception {
  	...
}

// 捕获异常
try {
  	// 可能出现异常的代码
} catch (异常类型1 变量) {
  	// 处理异常
} catch (异常类型2 变量) {
  	// 处理异常
}
// 
try {
  	// 
} catch (Exception e) {
  	e.printStackTrace (); // 打印异常对象的信息
}
// 此处选用Exception，可以扩大范围捕获所有异常，
```

整体思路：逐级上传，最外层捕获异常；

方法A调用方法B，方法B又调用了方法C；那么底层的方法C会将异常抛出给上一级调用者B，B将C抛出的异常和自身的异常再抛给上一级A，A作为最外层采用 `try-catch` 的方式捕获异常，并记录到日志中，将一部分信息呈现给用户；

### 处理方式

1、捕获异常，记录异常并响应合适的信息给用户

注意出现异常时，会暂停当前方法的执行并返回异常；
2、捕获异常，尝试重新修复

注意：如果直接在底层方法内采用循环会有问题。比如检测输入年龄是否合法，如果直接在底层循环输入，直到年龄符合范围，如果接受值为double，然后输入为字符等的话，会产生输入异常并直接上抛导致程序中断。因此可以在最顶层方法中使用

`try-catch` 并采用循环，即可接受底层所有的抛出异常并尝试修复，直到输入年龄合法；
