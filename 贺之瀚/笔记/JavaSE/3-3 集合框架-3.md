# 集合-3

## 一、集合并发修改异常

**并发** ：多个操作同时进行；

一个常见bug：使用for循环，`ArrayList` 调用`remove`方法会使后面一个元素移动到当前位置，但是删除完成后不会再对当前位置检查，而是移动到下一位置，从而导致漏删；解决方法也很简单，每次删除回退一个位置，或者倒着遍历；

同样，使用迭代器遍历集合的同时又在删除集合中的数据，程序就会出现并发修改异常的错误；

### 解决方法

1、不调用集合自身的`remove`方法，而是 **调用迭代器方法** 。

`it.remove()` 删除迭代器当前得到的数据，并且会在底层也做好类似`i--`操作；

注意，增强for和Lambda无法解决并发异常；只能使用迭代器；

2、for循环i--或者倒序遍历

```Java
Iterator<String> it = list.iterator();
while (it.hasNext()) {
  	String name = it.next();
  	if (name.contains ("李")) {
      	// 调用集合自身方法就会出现并发异常
      	// list.remove(name);

      	// 调用迭代器自身方法
      	// 迭代器的方法相当于会自动i--
      	it.remove();
    }
}
```

## 二、Collections

### 可变参数

一种特殊形参，定义在方法、构造器的形参列表里，格式为 `数据类型... 参数名称` ；

- 特点：可以不传数据给它，可以传一个或者同时传多个数据给它；也可以传一个数组给它；
- 常常用来灵活接收数据；

本质：在方法内部是一个 **数组** ，因此也具有数组拥有的方法；

#### 注意事项

1. 一个形参列表只能有 **一个** 可变参数（数量可变性会导致第二个接收不到参数）；
2. 可变参数必须放在形参列表的 **最后** ；

---

`Collections` 是一个用来操作集合的工具类；

|                                                                                |                                                                              |                                 |
| ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- | ------------------------------- |
| `public static <T> boolean addAll (Collection<? super T> c, T ... elements)` | 向集合中批量添加元素                                                         |                                 |
| `public static void shuffle(List<?> llst)`                                   | 打乱**List**集合中的元素顺序<br />（由于List是有序的，所以可以被打乱） | 洗牌(shuffle的意思本身就是洗牌) |
| `public static <T> void sort(List<T> list)`                                  | 对List中的元素排序，默认升序                                                 | 仅限于List                      |
| `public static <T> void sort(List<T> list,Comparator<? super T> c)`          | 对List集合中元素，按照比较器对象指定的规则进行排序                           | 仅限于List                      |

## 三、Map接口

Map集合即为双列集合，也叫 **键值对集合** ；

键值对：key-value/Entry对象；

Map集合的 **键不允许重复** ，但是值可以重复；

应用场景：购物车，商品类型=商品数量

`Map<K,V>` 所有特性与 **键** 有关；

## 四、Map方法

|                                               |                                             |
| --------------------------------------------- | ------------------------------------------- |
| put                                           | 加键值对                                    |
| `public int size()`                         | 集合大小                                    |
| `public void clear()`                       | 清空集合                                    |
| `public boolean isEmpty()`                  | 判断集合是否为空，为空返回true              |
| `public V get(object key)`                  | 根据键获取对应值，没有该键则返回`null`    |
| `public V remove(object key)`               | 根据键删除键值对，并返回值value             |
| `public boolean containsKey(objectkey)`     | 判断是否包含某个键key，包含返回true         |
| `public boolean containsValue(objectvalue)` | 判断是否包含某个值                          |
| `public Set<K> keySet()`                    | 获取Map的全部键key，以`Set` 式返回        |
| `public Collection<V> values()`             | 获取Map的所有值value                        |

Map的key属于无序不重复无索引，所以可以用Set；但是值可以重复，用set会丢数据，所以要用Collection

## 五、Map遍历

### 键找值

|                              |                               |
| ---------------------------- | ----------------------------- |
| `public Set<K> keySet()`   | 获取所有键的**集合** ； |
| `public V get(Object key)` | 根据键获取其对应的值          |

```Java
Map<String,double> map = new HashMap<>();
// 获取key的Set集合
Set<String> keys = map.keySet();
// 根据键获得value
for (String key : keys) {
  	double value = map.get(key);
  	System.out.println(key+" "+value);
}
```

### 键值对

核心是将键值对封装成 **Map.Entry对象** ；

Map.Entry本质上则是一个 **Map包中的接口** ；而这种遍历本质上是对Set集合的遍历，获取其中的键值对对象Map.Entry

| Map提供方法                          |                                 |
| ------------------------------------ | ------------------------------- |
| `Set< Map.Entry<K,V> > entrySet()` | 获取所有**键值对** 的集合 |

| Map.Entry提供的方法 |        |
| ------------------- | ------ |
| `K getKey ()`     | 获取键 |
| `V getValue()`    | 获取值 |

```Java
// 1.调用map.Entry<K,V>
Set<Map.Entry<String,double> entries = map.entrySet();
for (Map.Entry<String,double> entry : entries) {
  	String key = entry.getKey();
  	double value = entry.getValue();
  	System.out.println(key+"->"+value);
}
```

### Lambda

|                                                                  |  |
| ---------------------------------------------------------------- | - |
| `default void forEach(BiConsumer<? super K,？super V>action）` |  |

BiConsumer是一个接口；

Lambda的重写方法一般都是一个负责输出的，遍历的在forEach方法内部就弄好了；本质是键值对遍历；

```Java
// 匿名内部类
map.forEach (new BiConsumer<String,double>() {
  	@override
  	public void accept(String k, double v) {
      	System.out.println(k+"->"+v);
    }
});
// Lambda
map.forEach ((k,v) -> {
  	System.out.println(k+"->"+v);
});
map.forEach((k,v) -> System.out.println(k+"->"+v));
```

## 六、HashMap实现类

无序不重复无索引；

键和值**允许为null** ；

键只能存在一个，重复的键会 **覆盖** 前面的键值对；

```Java
Map<String,Integer> map = new Hashmap<>();
```

### 底层原理

和HashSet一样都是哈希表实现；

原来学的Set系列集合的底层就是基于Map实现的，只是Set集合中的元素只要key不要value；

因此实现机制和Set基本一致；

键的唯一性由hashCode和equals保证

## 七、LinkedHashMap

**有序** 不重复无索引；

### 底层原理

哈希表+双链表，双链表记录元素顺序保证有序，LinkedHashSet集合的底层原理就是LinkedHashMap；

## 八、TreeMap

不重复、无索引、可排序（只能对key，默认key的大小升序）；
TreeMap跟TreeSet集合的底层原理是一样的，都是基于红黑树实现的排序；

对于自定义类型，同样是两种方式；同样遵循就近原则；
