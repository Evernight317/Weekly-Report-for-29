# 字符流

字节流：适合复制文件等，不适合读写文本文件
字符流：适合读写文本文件内容

| 流         | 抽象类     | 实现类         |
| ---------- | ---------- | -------------- |
| 字符输入流 | `Reader` | `FileReader` |
| 字符输出流 | `Writer` | `FileWriter` |

## Java中char存储汉字（UTF-8编码）

UTF-8是字节编码，用于文件、网络传输；java中的*char为2字节*，采用UTF-16编码；

UTF-16：变长编码；将Unicode码点编码成1或2个16位单元；

读取时，先默认按照UTF-8将源文件字符转换为Unicode码点，然后再根据UTF-16存为char

---

## 一、FileReader

以内存为基准，可以把文件中的数据以字符的形式读入到内存中去；

| 构造器                                 |                                |
| -------------------------------------- | ------------------------------ |
| `public FileReader(File file)`       | 创建字符输入流管道与源文件接通 |
| `public FileReader(String pathname)` | 创建字符输入流管道与源文件接通 |


| 读取方法                           |                                                                                               |
| ---------------------------------- | --------------------------------------------------------------------------------------------- |
| `public int read()`              | 每次读取**一个字符** 返回，如果发现没有数据可读会返回-1                                 |
| `public int read(char[] buffer)` | 每次用一个字符数组去读取数据，返回 *字符数组读取了多少个字符* ，如果发现没有数据可读会返回-1 |

### 读取

同样可以用String的构造器，将char数组即字符数组转为String


## 二、FileWriter

以内存为基准，把内存中的数据以字符的形式写出到文件中去；

| 构造器                                                 |                                                               |
| ------------------------------------------------------ | ------------------------------------------------------------- |
| `public FileWriter(File file)`                       | 创建字节输出流管道与源文件对象接通                            |
| `public FileWriter(String filepath)`                 | 创建字节输出流管道与源文件路径接通                            |
| `public Filewriter(File file, boolean append)`       | 创建字节输出流管道与源文件对象接通，`append` true为追加管道 |
| `public Filewriter(String filepath, boolean append)` | 创建字节输出流管道与源文件路径接通，`append` true为追加管道 |


|                                               |                       |
| --------------------------------------------- | --------------------- |
| `void write(int c)`                         | 写一个字符            |
| `void write(String str)`                    | 写一个字符串          |
| `void write(String str, int off, int len)`  | 写一个字符串的一部分  |
| `void write(char[] cbuf)`                   | 写入一个字符数组      |
| `void write(char[] cbuf, int off, int len)` | 写入字符数组的一部分  |

### 写出

这里换行可以直接写字符串`"\r\n"`，因为write方法支持

注意：*字符输出流写出数据后，必须刷新流，或者关闭流* ，写出去的数据才能生效； 

每一次调用write方法都要进行一次系统底层调用，性能开销大；

字符输出流会在内存中分配**缓冲区** ，因此会写出至缓冲区，最后通过一次系统调用一次性写入；当 **缓冲区刷新** 时，就会执行一次写入操作，而 **缓冲区关闭** 也会执行一次刷新流操作；刷新为`FileWriter.flush()`，刷新后流可以继续使用，但是关闭后流无法继续使用；缓冲区如果满了，会自动执行一次刷新操作；
