# API-1

## 一、Object

### 常见方法

| 方法名                              | 基本作用                                               | 实际应用                                                                  |
| ----------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------- |
| `public String toString()`        | 返回对象的字符串表示形式<br />效果与直接输出对象名一致 | 让子类重写，以便返回<br />子类对象的内容                                  |
| `public boolean equals(Object o)` | 判断两个对象是否相等                                   | 让子类重写，以便用于<br />比较对象的内容是否相同<br />（IDE可以自动生成） |
| `protected Object clone()`       | 对象克隆                                               |                                                                           |

`clone` 函数由于被`protected` 修饰，所以无法被直接调用，需要重写该方法并在重写方法中调用父类`Object` 的 `clone`方法(IDE可以自动生成)；

同时，调用 `clone` 的类必须是 `cloneable`这一 **标记接口** 的实现类，

**标记接口** ：内容为空的接口

### 浅克隆&深克隆

| 浅拷贝                                                                                         | 深拷贝                                                                                                                                                                                                                         |
| ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 拷贝出的新对象，与原对象中的<br />数据一模一样（引用类型拷贝的只是地址），上面实现的就是浅拷贝 | <br />1、对象中基本类型的数据直接拷贝<br />2、对象中的字符串数据只拷贝**地址**，不会创建新的字符串（字符串存储在字符串常量池中，属于不可变对象）<br />3、对象中还包含的其他对象，不会拷贝地址，会创建**新对象** 。 |

深克隆需要在浅拷贝的基础上进一步重写 `clone` 方法

## 二、Objects

自动生成 equals 方法时，对于字符串采用的是 `Objects`类的`equals`方法比较，而不是字符串自己的equals

### Objects类&优势

被 `final` 修饰，即工具类，内部均为静态方法；

使用`Objects` 类的方法更安全、更准确。若直接调用对象方法，对象可能为空，此时就会引发空指针异常，但使用`Objects` 的方法安全且可以得到正确结果

常见方法

| 方法名                                               |                                         |
| ---------------------------------------------------- | --------------------------------------- |
| `public static boolean equals(Object a, Object b)` | 先做**非空判断** ，再比较两个对象 |
| `public static boolean isNull(Object obj)`         | 判断对象是否为null，为null返回true      |
| `public static boolean nonNull(Object obj)`        | 判断对象是否不为null，不为null返回true  |

- 实际使用时，`isNull` 可以简化为 `if (o == null)`

equals源码

```Java
public static boolean equals(Object a,Object b) {
	return (a == b) II (a != null && a.equals(b));
}
```

## 三、包装类

把8中基本类型变量包装成引用数据类型的类

| `byte` | `short` | `int`           | `long` | `char`            | `float` | `double` | `boolean` |
| :------: | --------- | ----------------- | -------- | ------------------- | --------- | ---------- | :---------: |
| `Byte` | `Short` | **Integer** | `long` | **Character** | `float` | `double` | `boolean` |

### 创建

使用 `包装类.valueof (对应基本类型)` 方法；

- **自动装箱**：可以自动把基本类型的数据转换成对象；
- **自动拆箱**：可以自动把包装类型的对象转换成对应的基本数据类型；
- 泛型和集合不支持基本数据类型，只能支持引用数据类型；使用时，也遵循自动装拆箱；

```Java
Integer a2 = Integer.valueof(12);

Integer a3 = 12;
int a4 = a3;

ArrayList <Integer> list = new ArrayList<>();
list.add(12)；
int rs = list.get(1)；
```

### 包装类的其他方法

1、把基本类型的数据转换成 `String` ，即使用 **对应包装类** 的 `toString` 方法；同时，实际也可采用 **`a + ""`** 的方法，自动转换成 `String`；

2、把 `String` 转换成数值本身对应的数据类型，使用 **对应包装类** 的 `parse基本类型名` 方法；实际推荐使用 **`valueof ()` **方法

```Java
Integer a=23;
// String rs1 = Integer.toString(a);// "23"
String rs2 = a + ""; // 更推荐这种

String strage = "29";
// int age = Integer.parseInt(strage);// 29 int
int age = Integer.valueof (strage); // 这种更好
```

## 四、StringBuilder

(这个就和C++中的String很像了)

`StringBuilder` 代表可变字符串对象，相当于是一个容器，它里面装的字符串是 **可变** 的，即可以被**操作** ；

与 String相比，由于String是不可变对象，因此`StringBuilder` 更适合做字符串的修改操作；

### 特性

### 构造器

| 构造器                               | 说明                                             |
| ------------------------------------ | ------------------------------------------------ |
| `public StringBuilder()`           | 创建空白对象                                     |
| `public StringBuilder(String str)` | 创建指定字符串内容的<br />`StringBuilder` 对象 |

### 方法

|                                           |                                                                                 |
| ----------------------------------------- | ------------------------------------------------------------------------------- |
| `public StringBuilder append(任意类型)` | 向串尾添加并返回**对象** 本身；                                           |
| `public StringBuilder reverse()`        | 反转字符串                                                                      |
| `public int length() `                  | 字符串长度                                                                      |
| `public String toString() `             | 把`StringBuilder` 转换为<br /> `String`，`String`更适合作为<br />对外API |

- 输出对象名，输出的是 **字符串内容** 而不是地址；
- `append`支持链式编程（和cin很像），由于返回值为**this**，即对象本身，故可以连续调用append，即 `s.append(666).append("黑马2").append(666));`

### 比较

对于字符串相关的操作，如频繁的**拼接、修改**等，StringBuidler效率更高（String每次拼接都是生成新的String）；

如果操作字符串较少/不需要操作/仅定义字符串变量，还是建议用String。

## 六、StringJoiner(JDK8)

和 `StringBuilder` 一样，也用来操作字符串，可看作内容可变的容器；特定场景下使用`StringJoiner`操作字符串，码量较 `StringBuilder` 更小

| 构造器                                               |                                           |
| ---------------------------------------------------- | ----------------------------------------- |
| `public StringJoiner(间隔符号)`                    | 指定拼接时的间隔符号                      |
| `public StringJoiner(间隔符号,开始符号,结束符号) ` | 指定拼接时的间隔符号、开始符号、结束符号  |

| 方法                                        |                                                        |
| ------------------------------------------- | ------------------------------------------------------ |
| `public StringJoiner add(要添加的字符串)` | 返回值为**对象本身**；只能添加**字符串**！ |
| `public int length()`                     | 字符串长度                                             |
| `public String toString()`                | 转换为`String`                                       |

当需要指定每个元素之间的间隔符号、首尾符号时，`StringJoiner` 效率高于`StringBuilder` ；
