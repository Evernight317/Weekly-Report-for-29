## 二、变量

### 字面量（`C++` 中的常量）

实际数据在程序中对应的形式。一共有六种，整数，小数，字符，字符串，布尔值， **空值** 最后一个稍微注意下

### 数据类型

基本数据类型共4类8种：整型 `byte short int long`	浮点型 `float double` 字符型 `char`布尔型 `boolean` 其中，整型默认  `int`，`byte` 1字节，`short`2字节；浮点默认`double`且8字节；`char` 为 **2字节** ；

引用数据类型如： `String`；引用类型存储方式见`1-3.md`

布尔值与整数 **不通用**

### 类型转换

类似于 `C++`  大范围自动转换小范围会报错，但可以强制；

`byte short char`在 **表达式中自动转换**  为`int`

强制类型转换格式： `(int) ('a')`

## 三、运算符

`java` 除了`>>/<<`之外，还有 `>>>` 无符号右移，高位补0；

无 `sizeof` ，无运算符重载；

涉及到布尔值的运算符及运算情况，布尔值和整数 **不通用；**

`java` 中， `+`与字符串相连时可以作为连接符号，结果仍是 **字符串** 。这个也可以用在`print` 相关的函数中

```Java
// 输出结果为"abc5"字符串
print ("abc"+5);
```

### 赋值运算符

扩展赋值运算符底层逻辑（ `+=` ）  `a=(a的类型)(a+ b);`
