# *字符集

开发时一般都需使用UTF-8；

 ~~本质：逻辑上字符与对应计算机底层二进制数据的映射；~~

---

## 一、ASCII编码

### 码点

字符--->码点---编码--->二进制数据

（不知道该怎么定义，用一个例子说明吧

ASCII中，每个字符对应的编号就是码点；

可以理解成每个字符的映射？

比如`'0'`对应48，码点就是48

### ASCII

0-127，由于不够8位，补了一个前导0，因此ASCII是用一个字节/1B存储的；

注意，ASCII**首尾都是0** ；

## 二、GBK

汉字内码扩展规范，国标

汉字编码字符集，包含了2万多个汉字等字符，GBK中一个中文字符编码成两个字节的形式存储；

GBK兼容了ASCII字符集，即采用ASCII的规则；

|            |       | 解码区分                                              |
| ---------- | ----- | ----------------------------------------------------- |
| 英文、数字 | 1字节 |                                                       |
| 汉字       | 2字节 | 汉字的*第一个字节的第一位一定是1* ，以此和ASCII区分 |

GBK能表示的为2^15-1=32767个字符，对于汉字来说足够；

## 三、Unicode字符集

统一码，也叫万国码；即容纳世界上所有文字、符号的字符集；

### UTF-32

四个字节表示一个字符，

但是这个的内存开销大，通信效率也降低，用的较少

### UTF-8

采取**可变长度编码** ，共分四个长度区：1个字节，2个字节，3个字节，4个字节；实际开发时一般采用**UTF-8** ；

|                |                          |  |
| -------------- | ------------------------ | - |
| 英文字符、数字 | 1字节<br />（兼容ASCII） |  |
| 汉字字符       | **3字节** ；      |  |

#### UTF-8编码规则

|       |                                             |
| ----- | ------------------------------------------- |
| 1字节 | 首位为0                                     |
| 2字节 | 第一个字节`110`，第二个字节`10`         |
| 3字节 | 第一个字节`1110`，第二、三字节`10`      |
| 4字节 | 第一个字节`11110`，第二、三、四字节`10` |

## 四、碎碎念

编码、解码使用字符集必须一致，否则会乱码；

英文、数字一般不会乱码，因为都兼容ASCII；

## 五、字符集的编解码

均为 *String的方法/构造器* ；

| String的编码方法                        |                                                                                       |
| --------------------------------------- | ------------------------------------------------------------------------------------- |
| `byte[] getBytes()`                   | 使用平台的**默认字符集** 将该String编码为一系列字节，将结果存储到新的字节数组中 |
| `byte[] getBytes(String charsetName)` | 使用**指定字符集** 将该String编码为一系列字节，将结果存储到新的字节数组中       |

then

| String的解码构造器                          |                                                                   |
| ------------------------------------------- | ----------------------------------------------------------------- |
| `String(byte[] bytes)`                    | 使用平台的**默认字符集** 解码指定的字节数组，构造新的String |
| `String(byte[] bytes,String charsetName)` | 使用**指定字符集** 解码指定的字节数组，构造新的String       |

指定字符集的话，直接写`"GBK" "UTF-8"` 即可；
