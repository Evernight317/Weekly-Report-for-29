# 缓冲流

|                |                          |  |
| -------------- | ------------------------ | - |
| 字节缓冲输入流 | `BufferedInputStream`  |  |
| 字节缓冲输出流 | `BufferedOutputStream` |  |
| 字符缓冲输入流 | `BufferedReader`       |  |
| 字符缓冲输出流 | `BufferedWriter`       |  |

原始流/低级流

包装流/处理流

对原始流进行包装，以提高原始流读写数据的性能

## 字节缓冲输入/输出流

输入/输出在内存中开辟8KB的缓冲区

字节缓冲输入流自带了8KB缓冲池；字节缓冲输出流也自带了8KB缓冲池

| 构造器                                                   |                                                                        |
| -------------------------------------------------------- | ---------------------------------------------------------------------- |
| `public BufferedInputStream(InputStream is)`           | 把低级的字节输入流包装成一个高级的缓冲字节输入流，从而提高读数据的性能 |
| `public BufferedOutputStream(OutputStream os)`         | 把低级的字节输出流包装成一个高级的缓冲字节输出流，从而提高写数据的性能 |
| `public BufferedInputStream(InputStream is, int size)` | 可以声明缓冲区大小，如16KB                                             |

## 二、字符缓冲输入/输出流

### 1.BufferdReader

自带 **8K(8192)** 的字符缓冲池，可以提高字符输入流读取字符数据的性能；

此处是**8192个字符** ；

|                                     |                                                                                 |
| ----------------------------------- | ------------------------------------------------------------------------------- |
| `public BufferedReader(Reader r)` | 把低级的字符输入流包装成字符缓冲输入流管道，从而提高字符输入流读字符数据的性能  |

`BufferedReader` 还可以**按行读取字符** ；

|                              |                                                            |
| ---------------------------- | ---------------------------------------------------------- |
| `public String readLine()` | 读取一行数据返回，如果没有数据可读了，会返回`null`    |

### 2.BufferedWriter

自带8K的字符缓冲池，可以提高字符输出流写字符数据的性能；

同样是**8192个字符** ；

|                                     |                                                                                      |
| ----------------------------------- | ------------------------------------------------------------------------------------ |
| `public BufferedWriter(Writer r)` | 把低级的字符输出流包装成一个高级的缓冲字符输出流管道，从而提高字符输出流写数据的性能 |

字符缓冲输出流新增的功能：**换行** ；

|                           |      |
| ------------------------- | ---- |
| `public void newLine()` | 换行 |

## 性能分析

一般情况下，字节数组较小时，缓冲流优于低级流；

但当低级流使用更大的字节数组时，能够显著降低时间，甚至反超缓冲流，但是也存在明显的边际效应。比如复制一个800MB的视频文件，字节数组为32KB和64KB的时间差距极小，但内存占用翻倍；
