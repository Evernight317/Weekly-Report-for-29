### 3.Calendar

本质是一个抽象类

`Calendar` 代表的是系统此刻时间对应的日历，通过`Calendar`可以单独获取、修改时间中的年、月、日、时、分、秒等；

当想要修改时间为特定数量时， Date较为繁琐，更适合用Calendar处理；

和Date一样都是 **可变对象** ，修改后原始时间会丢失；

日历中， **月份从0开始计** ，因此要+1处理；

| 方法                                      |                                                                 |
| ----------------------------------------- | --------------------------------------------------------------- |
| `public static Calendar getInstance()`  | 获取`Calendar` 对象，注意月份时**从0开始** 计的，+1转换 |

| `public final Date getTime()`           | 获取`Date`对象                                                |
| `public long getTimeInMillis()`         | 获取对应的毫秒值                                                |
| `public void set(int field,int value)`  | 修改某个信息                                                    |
| `public void add(int field,int amount)` | 为某个信息增加/减少指定的值                                     |

## 八、Lambda表达式（>JDK8）

用于简化匿名内部类的代码写法

```Java
(被重写方法的形参列表）-> {
	被重写方法的方法体代码
}
```

Lambda只能对函数式接口的匿名内部类简化！  

**函数式接口** ：只有一个抽样方法的接口；实际应用中，函数式接口上方会有注解`@FunctionalInterface`；

### 省略规则

- 参数类型可以省略不写；
- 如果只有一个参数，参数类型可以省略，同时`()`也可以省略；
- 如果Lambda表达式中的方法体代码只有一行代码，可以省略`{}`不写，同时要省略分号！此时，如果这行代码是`return`语句，也必须去掉`return`不写；

比如，之前使用的`setAll`方法中的接口参数`IntToDoubleFunction` 以及自定义比较中的 `Comparator`就属于函数式接口，可以使用Lambda并进行简化；

```Java
// 正常的匿名内部类写法
Arrays.setAll (prices,new IntToDoubleFunction() {
	@Override
	public double applyAsDouble(int value){
		return prices[value] * 0.8;
    }
});
// Lambda
Arrays.setAll (prices,(int value) -> {
  	return price[value]*0.8;
});
// 进一步简化
Arrays.setAll (prices, value -> price[value]*0.8));
```

## 九、方法引用

可以用来进一步简化Lambda；`::`标志性符号

### 1.静态方法引用

格式：`类名::静态方法`；

如果某个Lambda表达式里只是调用一个静态方法，并且 **前后参数的形式一致** ，就可以使用静态方法引用；

```Java
// 定义一个静态方法
class CompareByData {
  	public static int compareByAge (student o1, student o2) {
      	return o1.age-o2.age;
    }
}
// 简化的Lambda，但其仍满足Lambda简化函数式接口的条件
// 因此sort的第二个参数是要求实现compare<T>的比较器，这里是省略后的写法
// 即调用静态方法实现比较作用，完整的匿名内部类如下
// Arrays.sort (students, new Compare<students> () {
//   	@Override
//   	public int compare (student o1,student o2) {
//       	return CompareByData.compareByAge (o1,o2);
//     }
// });
Arrays.sort (students, (o1,o2) -> CompareByData.compareByAge (o1,o2));
// 静态方法引用简化
Arrays.sort (students, CompareByData::compareByAge);
```

### 2.实例方法引用

格式：`对象名::实例方法` ；
如果某个Lambda表达式里只是调用一个实例方法，并且前后参数的形式一致，就可以使用实例方法引用；

```Java
CompareByData compare = new CompareByData ();
// Lambda，这里变成了实例方法
Arrays.sort (students, (o1,o2) -> compare.compareByAge (o1,o2));
// 实例方法引用
Arrays.sort (students, compare::compareByAge);
```

### 3.特定类型方法引用

格式：`类型:方法`；
如果某个Lambda表达式里只是调用一个实例方法，并且前面参数列表中的第一个参数是作为方法的 **主调** ，后面的所有参数都是作为该实例方法的 **入参** ，则此时就可以使用特定类型的方法引用。

以String的排序为例，默认为从首字母开始按照ASCII大小比较(A<B<C<a)，现在要求忽略大小写排序，可以使用String中的`compareToIgnoreCase` 方法，该方法能够返回符合比较规则的int值；

在代码中，`o1`是方法的调用者/主调，o2及后面的参数则在比较方法中出现；

```Java
// 匿名内部类
Arrays.sort (names, new Comparetor<String> () {
  	@Override
  	public int compare (String o1,String o2) {
      	return o1.compareToIgnoreCase (o2);
    }
});
// Lambda
Arrays.sort (names, (o1,o2) -> o1.compareToIgnoreCase (o2));
// 类型引用，这里的方法属于String
Arrays.sort (names, String::compareToIgnoreCase);
```

### 4.构造器引用

格式： `类名::new` ；
如果某个Lambda表达式里只是在创建对象，并且前后参数情况一致，就可以使用构造器引用；

如，当一个接口的匿名内部类的重写方法仅创建了一个对象，且方法的参数和有参/无参构造器相同，即可简化；
