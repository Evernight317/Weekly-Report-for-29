## 一、目录结构

- 目录是**树形结构**；
- Linux没有盘符这个概念，只有一个根目录`/`，所有文件都在它下面；
  - Linux只有一个顶级目录，即根目录；
- 路径层级用`/`表示；

### `/`在Linux系统中表示

- 出现在开头的/：根目录
- 出现在后面的/：层次关系

## 二、

### 命令基础格式

`command [-options] [parameter]`

- command
- `-options`：命令的一些选项，可以通过选项控制命令的行为细节（怎么做）；
- `parameter`：命令的参数，多数用于命令的指向目标等；
- **单字母的短选项**可以**合并**一起写；
- Linux命令，其实它们的本体就是一个个的**二进制可执行程序**；

---

### `ls`命令

`ls [-a -l -h] [Linux路径]`

- 直接使用`ls`命令本体，表示：以平铺形式，列出当前工作目录下的内容；
- Linux系统的命令行终端，在启动的时候，默认会加载*当前登录用户的HOME目录*作为当前工作目录；
- **HOME目录** ：每个Linux操作用户在Linux系统的个人账户目录，`/home/用户名`；

#### 选项

- `-a` ：all， 包括隐藏的；
- `-l` ：以列表（竖向排列）的形式展示内容，并展示更多信息；
- `-h` ：以易于阅读的开形式，列出文件大小，必须和`-l` **一起使用**；

### 目录切换-cd&pwd

`cd [Linux path]` `pwd`

change directory

print work directory 查看当前工作目录

- cd无参数即为回到HOME；

### 绝对路径&相对路径

- 绝对路径：以根目录为起点，描述路径的一种写法，路径描述以`/`开头；
- 相对路径：以**当前目录**为起点，描述路径的一种写法，路径描述无需以`/`开头

### 特殊路径符

- `.` ：当前
- `..` ： 上一级
- `~` ：HOME目录；

### 创建目录

make directory

`mkdir [-p] Linux路径`

- `-p` ：自动创建不存在的父目录，适用于创建连续多层级的目录；
- 路径必填，绝对相对均可；
- 创建文件夹需要修改权限，必须**在HOME内操作**；

### 文件操作

`touch Linux路径`

创建文件

`cat Linux-path`

`more Linux-path`

查看文件

- cat是直接将内容全部显示出来；
- more支持翻页，如果文件内容过多，可以分页展示；

`cp [-r] para1 para2` copy

复制文件

- `-r` 用于**复制文件夹**使用，表示递归（即复制所有内容；
- para1即被复制文件/文件夹，para2即目标；

`mv para1 para2` move

移动文件

- para1即被移动文件夹；
- para2目标点，如果目标不存在，则进行**改名**，确保目标存在；

`rm [-r -f] para1 para2 ...`

- `-r` 同样对**文件夹**使用，即删除文件夹；
- `-f` force，**强制删除**，即不弹出确认信息；
  - 普通用户删除内容不会弹出提示，只有root管理员用户删除内容会有提示，所以一般普通用户用不到-f选项
- **通配符`*`** ，即匹配任意内容（可为空），可用于模糊匹配
  - `test*` `*test` `*test*`
- 危险命令：`rm -rf /` `rm -rf /*`

### 查找

Linux命令，其实它们的本体就是一个个的二进制可执行程序；

`which 要查找的命令`

用于查找命令的程序文件的位置；

`find 起始路径 -name "被查找文件名"`

按文件名查找文件

- 按**文件名**查找；
- find同样支持通配符`*`；

`find 起始路径 -size +|-n[kMG]`

按文件大小查找文件

- +、-表示大于、小于；
- n是表示文件大小
- kMG就是大小单位，k-kb，M-MB，G-GB；
- `find / -size -10k` 从根目录开始找所有<10kb的文件

### grep

`grep [-n] 关键字 文件路径`

~从文件中通过关键字过滤文件行；~

grep本质是一个**文本过滤器** ，所以只要是文本都可以过滤（包括Terminal中筛选进程）；

- `-n`，可选，表示在结果中显示匹配的行的行号；
- 关键字，必填，表示过滤的关键字，一般用`""`；
- 文件路径，必填，表示要过滤内容的文件路径，可作为**内容输入端口**；

### wc

`wc [-c -m -l -w] 文件路径`

可以通过WC命令统计文件的行数、单词数量等

- `-c`，统计bytes数量
- `-m`，统计字符数量
- `-l`，统计行数
- `-w`，统计单词数量
- 文件路径，被统计的文件，可作为**内容输入端口**；

### 管道符

将管道符左边命令的结果，作为**右边命令的输入**；

`cat itheima.txt | grep itheima` 在这个txt中筛选itheima内容；

- `|`可以嵌套使用；

### echo

在命令行内输出指定内容；

`echo 输出内容`

如`echo "Hello Linux"`

- 复杂内容可用`""`包围，
- 想要执行命令的话，可以使用**反引号`** ，被反引号包围的内容，会被作为**命令**执行，而非普通字符

```Shell
# 反引号`
echo `pwd` # 执行pwd命令
```

### 重定向

`>`

将左侧命令的结果，**覆盖**写入到符号右侧指定的文件中；

 `>>`

将左侧命令的结果，**追加**写入到符号右侧指定的文件中；

### tail

查看文件尾部内容，跟踪文件的最新更改；

`tail [-f -num] Linux路径`

- `-f`，*持续跟踪文件更改*；
- `-num`查看尾部行数，默认**10行**；

## Linux的文本编辑器

vim/nano

vim就是命令行模式下的文本编辑器，用来编辑文件；

---

### vim的三种模式

#### 命令模式

所敲的**按键**编辑器*都理解为命令*，以命令驱动执行不同的功能

不能自由进行文本编辑；

- 进入：`vi filename`
- 退出：`wq`

#### 输入模式

可以对文件内容进行自由编辑

- 命令模式进入插入模式：`iao`
- 返回命令`ESC`

#### 底线命令模式

以`:`开始，通常用于文件的保存、退出；

- 进入：`:`

### 进入vim

`vim 文件路径`

- 若文件不存在，编辑新文件；
- 若文件存在，编辑已有文件；

### 命令模式快捷键

|       |                                          |
| ----- | ---------------------------------------- |

| `o` | 在当前光标**下一行**进入输入模式   |
| `O` | 在当前光标**上一行**进入输入模式   |

- 在**输入模式**下，输入`esc`即可返回命令模式；
