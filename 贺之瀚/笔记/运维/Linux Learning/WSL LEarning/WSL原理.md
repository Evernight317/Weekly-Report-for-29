# WSL

## `/mnt`

linux的一个标准目录，全称是mount

作为一个**挂载点**，将外部的存储设备（如U盘、网络共享设备等）接入到Linux的文件树中

### 挂载mount

Linux中没有盘符的概念，所有都位于根目录`/`下。当插入U盘时，就需要分配一个文件夹来代表U盘，相当于把一个文件夹绑定到U盘，即**挂载** ，而`/mnt`就是这个的默认目录

- 对于WSL来说，重点是win系统的磁盘，命名规则为`/mnt/盘符`，自动生成并挂载
- 对于Ubuntu来说，一般是`/media/用户名/设备名`，自动生成挂载
- 手动挂载命令`sudo mount 物理接口 挂载文件夹路径`
