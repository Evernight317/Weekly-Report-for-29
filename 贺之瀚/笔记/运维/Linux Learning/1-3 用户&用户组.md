# 用户&用户组

## 超管root

- 超管有最大的权限
- 普通用户的权限，一般在其HOME目录内是不受限的，一旦出了HOME目录，大多数地方，普通用户仅有只读和执行权限，无修改权限

### 切换用户

`su [-] [用户名]` switch user

- `-`表示是否在切换用户后加载环境变量；
- 切换用户后，可以通过**exit**命令退回上一个用户，也可以使用快捷键：**ctrl+d** ；
- 普通用户执行切换用户要输密码，root不用；

### 提权

`sudo 命令` SuperUser Do

- 不是所有的用户，都有权利使用sudo，需要为普通用户**配置sudo认证** ；
- 两种方式： 1、加入sudo组 2、在`/etc/sudo`中配置

配置方式：切换root后执行`visudo`，`用户名 ALL=(ALL) NOPASSWD: ALL`

## 用户组

均需要**root**；

```Shell
# 创建用户组
groupadd 用户组名
# 删除用户组
groupdel 用户组名
```

### 用户管理

#### 添加用户

`useradd [-g -d] 用户名`

- `-g` 指定用户组，不指定则创建并加入同名组；-g需要组已经存在，如已存在同名组，必须使用-g；
- 指定用户HOME路径，不指定则默认`/home/用户名`；

#### 删除用户

`userdel [-r] 用户名`

- `-r`，删除用户的HOME目录，否则保留；

#### 查看用户所属组

`id [用户名]`

- 不提供用户名则查看自身；

#### 修改用户所属组

`usermod -aG 用户组 用户名`

#### 查看当前系统用户

`getent passwd`

信息顺序：用户名:密码(x):用户ID:组ID:描述信息(无用):HOME目录:执行终端(默认bash)

## 权限控制

`ls -l` ：以列表形式查看内容，显示权限细节；

顺序为：文件、文件夹权限控制信息/文件、文件夹所属用户/文件、文件夹所属用户组；

### 权限控制信息

10个槽位：

- 1：`-`：文件  `d`：文件夹 `l`：软链接；
- 2-4：所属用户权限
- 5-7：所属用户组权限
- 8-10：其他用户权限；
- 分别为`rwx` ：读read、写write、x作为程序执行，对于文件夹是可以cd进入，`-`表示无权限；

## 权限修改

### chmod

修改文件、文件夹的权限信息；

(change model?)

`chmod [-R] 权限 文件/文件夹`

- `-R` ：对文件夹内的全部内容应用同样的操作；
- `u`表示user所属用户权限，`g`表示group组权限，`o`表示other其它用户权限

```Shell
chmod u=rwx,g=rx,o=x hello.txt 
```

#### 快捷写法

权限用**3位数字**来代表，第一位数字表示用户权限，第二位表示用户组权限，第三位表示其它用户权限；

- r记为4，w记为2，x记为1；

### chown

(change owner?)

修改文件、文件夹的所属用户和用户组；

`chown [-R] [用户][:][用户组] 文件/文件夹`

- `-R` 对文件夹内的全部内容应用同样的操作；
- `:` 用于分隔用户和用户组；
- 剩下的就是修改所属用户/用户组；
