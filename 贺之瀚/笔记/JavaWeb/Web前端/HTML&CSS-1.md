# HTML&CSS

## 一、介绍

官方文档 [W3school](https://www.w3school.com.cn/)

### HTML

HTML(HyperText Markup Language)，超文本标记语言；

| 超文本                                                                             | 标记语言         |
| ---------------------------------------------------------------------------------- | ---------------- |
| 超越了文本的限制，比普通文本更强大，除了文字信息，还可以定义图片、音频、视频等内容 | 由标签构成的语言 |

- HTML标签都是 **预定义** 好的。例如：使用`<a>`展示超链接，使用`<img>`展示图片，`<video>`展示视频；
- HTML代码直接在浏览器中运行，HTML标签由浏览器解析

记事本中的就是普通文本；

### CSS

CSS (Cascading Style Sheet)，即层叠样式表，用于控制页面的样式（表现）；

## 二、HTML入门

#### 结构标签

最外层是`<html></html>`，html中有子标签`<head></head>` 和`<body></body>`，head中通过`<title></title>` 指定标题；

```HTML

<html>
  	<head>
      	<title>标题</title>
    </head>

  	<body>
  
    </body>
</html>
```

```html
<html>
    <head>
        <title>Hello World</title>
    </head>

    <body>
        <h1>Hello World</h1>
        <h2>HTML初体验</h2>
        <h3>兄弟你好香</h3>
        <h4>好大好深</h4>
        <h5>18cm硬邦邦</h5>
        <img src ="D:\Desktop\¿.png"/> 
    </body>
</html>
```

- HTML的标签不区分大小写
- 标签中的属性单双引号均可
- 语法结构松散，即不严格，如`</html>` 去掉也不影响渲染结果；

## 三、基础标签&样式

### 1.标题排版

*VSCode可以通过快捷键`!`生成HTML模板* ；

#### 图片标签

`<img src="" width="" height="">`
`src`：指定图像的URL（绝对路径/相对路径）
`width`：图像的宽度（像素/相对于父元素的百分比）
`height`：图像的高度（像素/相对于父元素的百分比）

- 绝对路径分两种：绝对磁盘路径、绝对网络路径；后者需要图片在网络中存在，并且使用时需联网；
- 相对路径中的两个符号：`./` 当前目录，可省略；`../`上一级目录，不可省略；
- 高度宽度的单位有两种：`px`和`%`，前者代表像素，后者为相对父元素的百分比；*一般只设置一个的像素，另一个会等比例缩放* ；
- 文字：图片后要跟文字的话，直接在`<img>`后写出即可；

### 2.标题样式

#### CSS引入方式

1、行内样式：写在标签的style属性中（不推荐）`<h1 style="xx:xx; xx:xx">...</h1>`

2、内嵌样式：写在style标签中（可以写在页面任何位置，但通常约定写在head标签中）

```HTML
<style>
  	/* h1称为选择器 */
  	h1 { 
      	xxx: xxx;
      	xxx: xxx;
    }
</style>
```

3、外联样式：写在一个单独的`.css`文件中（需要通过link标签在网页中引入）

```HTML
h1 {
	xxx: xxx;
	xxx: xxx;
}

<link rel="stylesheet" href="css/news.css">
```

#### 颜色表示

| 表示方式       | 表示含义                                                                                | 取值                                                                                            |
| -------------- | --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 关键字         | 预定义的颜色名                                                                          | green                                                                                           |
| rgb表示法      | **红绿蓝**三原色，每项取值范围：0-255， 也就是说三个值*依次为红绿蓝的颜色值* ； | `rgb(0,0,0)`<br />`rgb(255,255,255)` <br />`rgb(255,0,0)`                                |
| 十六进制表示法 | `#`开头，将rgb的数字转换成十六进制表示，同样依次为红绿蓝；                            | `#000000`、`#ff0000`、<br />`#cccccc`；如果两位相同，就可以简写为`#000`、<br />`#ccc` |

文本内容颜色可以通过style中的`color`来指定；

#### `<span>`标签

#### CSS选择器

用来选取需要设置样式的元素(标签）；

优先级：*id选择器>类选择器>元素选择器* ；

类名和id名称是可以自定义的；

```HTML

}
<!-- 类选择器 -->

}
<!-- 元素选择器 -->
元素名称 {

}
```

#### CSS属性

`color` ：设置文本颜色；

`font-size` ：设置字体大小

### 5.正文页面布局

#### CSS盒子模型

页面中所有的元素（标签），都可以看做是一个**盒子** ，由盒子将页面中的元素包含在一个矩形区域内，通过盒子的视角更方便的进行页面布局

由内容区域content、内边距padding、边框border、外边距margin组成；

#### 布局标签

实际开发网页中，会大量频繁的使用`<div>`和`<span>`这两个没有语义的布局标签；

| div标签                                                                                                                | span标签                                                                                     |
| ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 1、一行只显示一个（独占一行）<br />2、宽度默认是父元素的宽度，高度默认由内容撑开<br />3、可以设置宽高（width、height） | 1、一行可以显示多个<br />2、宽度和高度默认由内容撑开<br />3、不可以设置宽高（width、height） |

#### 版心居中

`margin` 在不同参数数量时的对应为

`margin: 10px 5px 15px` ：上下分别为10/15，左右为5px；

`margin 10px 5px` ：上下为10px，左右为5px；

`margin 10px` ：上下左右均为10；

`auto` 浏览器自动推导；

因此，`margin 0 auto` 意为上下为0，左右浏览器自动推导；

#### CSS属性

`width` 设置宽度

`height` 高度

`border` 设置边框属性，如`1px solid #000`

`padding` 内边距

`margin` 外边距

注意：如果只需要设置某一个方位的边框、内边距、外边距，可以在属性名后加上`-位置` ，如: `padding-top`即为上方的内边距、`padding-left`、`padding-right` ；

### 7.表单标签

在网页中主要负责数据采集功能，如注册、登录等数据采集；用户登录界面就是一个表单，点提交就可将数据提交到后端；

表单标签：`<form>`，表单包括一系列的表单项；

表单项：不同类型的input元素、下拉列表、文本域等；表单项 *必须有name属性* 才可以提交,name属性在提交时可以起到键key的作用；

表单属性如下

`action` ：表单数据提交的URL地址，不指定则默认提交到当前页面；

`method` ： 表单提交方式；

方式有两种

`get` ：表单数据拼接在url后面，（浏览器中查看URL即可发现）如`？username=Tom`，由于URL长度有限制，因此大小有限制；

`post` 表单数据在**请求体（消息体）** 中携带，大小没有限制；可在开发者模式的网络模块中查看；
