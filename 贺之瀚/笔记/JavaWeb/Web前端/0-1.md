# Web

## 一、Web网站工作流程

1、网页程序/前端程序，运行在前端服务器；

2、Java程序/后端程序，运行在后端服务器，负责数据的逻辑处理；

3、数据库服务器，负责数据的存储、管理；

浏览器根据域名去请求对应前端服务器，前端服务器接收到请求后返回相应的前端代码，浏览器能够解析前端代码，并使其呈现出相应的网页结构（一个架子，没有数据）；前端代码中有获取数据的URL，浏览器根据这个URL去请求相应的后端服务器，后端服务器再向数据库服务器发送请求，返回对应的数据，再传回浏览器，填充进解析的前端框架中，形成完整的网页；

上述为前后端分离开发，前端开发前端程序，后端开发后端程序；

混合开发：前后端代码写在一起，浏览器在请求后直接收到框架+数据；
