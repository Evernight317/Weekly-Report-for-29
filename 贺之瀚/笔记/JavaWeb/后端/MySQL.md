# MySQL

数据库(DataBase)：存储和管理数据的仓库；

数据库管理系统(DataBase Management System ,DBMS)：操纵和管理数据库的大型软件；

SQL:Structured Query Language结构化查询语言，操作**关系型数据库** 的编程语言，定义了一套操作关系型数据库统一标准；

---

## 一、安装&工程使用

mysql连接语法：`mysql -u用户名 -p密码[-h数据库服务器IP地址 -P端口号]` 默认端口号是3306；

工程上，mysql运行在机房服务器中，通过mysql客户端访问数据库；

## 二、数据模型

**关系型数据库**（RDBMS）：建立在关系模型基础上，由多张相互连接的**二维表** 组成的数据库；

**二维表** ：就是excel那种表格；

每张表之间通过一个或多个属性相连；

- 使用表存储数据，格式统一，便于维护
- 使用SQL语言操作，标准统一，使用方便，可用于复杂查询

## 三、SQL简介

SQL：一门操作**关系型数据库** 的编程语言，定义操作所有关系型数据库的统一标准；

### 通用语法

- SQL语句可以单行或多行书写，以分号`;`结尾
- SQL语句可以使用空格/缩进来增强语句的可读性
- MySQL数据库的SQL语句不区分大小写
- 注释：
- - 单行注释：`-- 注释内容`或 `# 注释内容`后者为mysql特有
  - 多行注释：`/* 注释内容*/` 和java一致；

### SQL语句分类

四大类，主要了解前三类

|     | 全称                       |                                                        |
| --- | -------------------------- | ------------------------------------------------------ |
| DDL | Data Definition Language   | 数据定义语言，用来定义数据库对象(数据库，表，字段)     |
| DML | Data Manipulation Language | 数据操作语言，用来对数据库表中的数据进行增删改         |
| DQL | Data Query Language        | 数据查询语言，用来查询数据库中表的记录                 |
| DCL | Data Control Language      | 数据控制语言，用来创建数据库用户、控制数据库的访问权限 |

## 四、数据库设计-DDL

DDL，数据定义语言；

### 数据库操作

`database` 也可以替换成`schema` ；

```MySQL
-- 查询所有数据库
show databases;
-- 查询当前数据库
select database;

-- 使用数据库
use 数据库名;

-- 创建数据库 []为可加项
-- 加上后如果数据库已存在，则不进行操作且不报错
create database [if not exists] 数据库名;

-- 删除数据库
drop database [if exists] 数据库名;
```

### 表操作-创建&约束

`[...]`表示可选项；

创建表时，最后一个字段不能加`,`；

（字段相当于是类）

```MySQL
create table 表名(
	字段1 字段类型 [约束] [comment字段1注释]，
	字段n 字段类型 [约束] [comment字段n注释]
)[comment表注释]；
```

约束：作用于表中字段上的规则，用于限制存储在表中的数据；

可以保证数据库中数据的正确性、有效性和完整性；

| 约束     |                                                                                 | 关键字                                                                        |
| -------- | ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 非空约束 | 限制该字段值不能为null                                                          | `not null`                                                                  |
| 唯一约束 | 保证*字段的所有数据* 都是唯一、不重复的                                       | `unique`                                                                    |
| 主键约束 | 主键是*一行数据的唯一标识* ，要求非空且唯一                                   | `primary key`<br />后面跟`auto_increment` 可以**让主键自动增长** ； |
| 默认约束 | 保存数据时，如果未指定该字段值，则采用默认值，需要在后面**紧跟默认值** ； | `default`                                                                   |
| 外键约束 | 让两张表的数据建立连接，保证数据的一致性和完整性                                | `foreign key`                                                               |

- mysql中，字符串是`varchar(10)`，`()`是规定字符串长度，超出报错；
- `char(1)`是一个固定长度字符串类型，`(1)`表示只能存储一个字符；
- comment后的注释用`''`；

```MySQL
create table tb_user (
    id int primary key auto_increment comment 'id',
    username varchar(20) not null unique comment '用户名',
    name varchar(10) not null comment '姓名',
    age int comment '年龄',
    gender char(1) default '男' comment '性别'
)
```

## 六、数据库操作-DML

数据操作语言，涉及到增删改；

### INSERT 添加数据

mysql中，通过`now()`可以*获取当前时间（datetime）* ；

日期时间类型添加时也要加上 `''`，

为所有字段插入值时，可以省去字段的`()` 直接写value即可；

```MySQL
-- 指定字段添加数据
insert into 表名(字段名1,字段名2) values(值1,值2);
-- 全部字段添加数据
insert into 表名 values(值1,值2...);
-- 批量添加数据（指定字段）
insert into 表名(字段名1，字段名2) values(值1，值2),(值1，值2)；
-- 批量添加数据（全部字段）
insert into 表名 values(值1,值2,...),(值1，值2,..);
```

- 插入数据时，指定的字段顺序需要与值的顺序是一一对应的；
- **字符串** 和**日期型** 数据应该包含在`''`中；
- 插入的数据大小，应该在字段的规定范围内，比如`varchar`的范围；

### UPDATE 更新数据

数据回显；

如果有`updatetime`的话，也要进行更新；

```MySQL
update 表名 set 字段名1=值1,字段名2=值2,...[where条件];
```

没有`where`条件则会更新**整张表** 数据；

### DELETE 删除数据

```MySQL
delete from 表名 [where条件];
```

同样，没有`wh ere`会删除**整张表** 数据；

DELETE语句不能删除**某一个字段** 的值（如果要操作，可以使用UPDATE，将该字段的值置为NULL）；

## 七、DQL-单表查询

数据查询语言

基本查询+条件查询+分组查询+排序查询+分页查询；

```MySQL
select 字段列表
	from 表明列表
  
	where 条件列表
  
	group by 分组字段列表
	having 分组后条件列表

	order by 排序字段列表

	limit 分页参数
```

### 1.基本查询

比如说，对于第一个：查询公司的员工姓名和对应工号，就可以查询出所有对应的表格；

如果别名有空格等特殊字符的话，要*用`''`表示是一个整体* ；

```MySQL
-- 查询多个字段
select 字段1,字段2,字段3... from 表名;

-- 查询所有字段
-- 方法一，先打表名，利用GUI客户端补全选择所有
-- 方法二，使用通配符* select * from 表名
-- 方法二不推荐，性能开销大
select (自动补全) from 表名;

-- 设置别名
select 字段1 [as 别名1],字段2 [as 别名2] from 表名；

-- 去除重复记录
select distinct 字段列表 from 表名；
```

### 3.聚合函数

将一列数据作为一个**整体** ，进行**纵向计算** ；

语法：`select 聚合函数(字段列表) from 表名；`

| 函数      |          |
| --------- | -------- |
| `count` | 统计数量 |
| `max`   | 最大     |
| `min`   | 最小     |
| `avg`   | 平均值   |
| `sum`   | 求和     |

count有三种方式 `count(字段/常量/*)` ，并且count不对`null` 进行运算，因此`count` 必须作用于**非空字段** ；

`count(常量)`：统计当前表中总行数（包括null？？？）最经典的写法是`count(1)` 这个属于历史遗留问题；

`count(*)` 现在优化是最好的，推荐使用这个；

对于所有聚合函数，`null` 均不参与运算；

### 4.分组查询

`select 字段列表 from 表名 [where 条件] group by 分组字段名 [having 分组后过滤条件]`

- `where` 和 `having` 区别
  - 执行时机不同：where是**分组之前** 进行过滤，不满足where条件，不参与分组；而having是**分组之后** 对结果进行过滤；
  - 判断条件不同：where不能对聚合函数进行判断，而having可以；
- 分组之后，查询的字段一般为**聚合函数** 和**分组字段** ，查询其他字段无任何意义；（可以认为聚合函数表示的就是对分组字段的每个组进行处理后的内容）
- 执行顺序：`where` >聚合函数>`having`；

### 5.排序查询

`select 字段列表 from 表名 [where 条件列表] [group by 分组字段] order by 字段1 排序方式1,字段2 排序方式2...；`

|                |                  |
| -------------- | ---------------- |
| 升序（默认值） | `ASC` ascent   |
| 降序           | `DESC` descent |

- 如果是多字段排序，当第一个字段值**相同** 时，才会根据后一个字段进行排序；

### 6.分页查询

分页查询就是将搜索结果分成多页展示，防止因为结果过多加载时间过长等影响用户体验（实际好像时一次展示几个结果，跳转到对应页数时前端在发送一次请求，后端进行响应）

`select 字段列表 from 表名 limit 起始索引,查询记录数;`

查询记录数指的就是每页展示的数据数量；

- 起始索引**默认从0开始** ，起始索引= `(查询页码-1)*每页显示记录数` ；
- 分页查询是数据库的方言，不同的数据库有不同的实现，MYSQL中是`LIMIT`；
- 如果查询的是第一页数据，起始索引可以**省略** ，直接简写为`limit 10`；
