# 事务管理

数据库中的事务：一组操作集合；

spring已经封装了事务语句；

## Spring事务管理

| 注解               | 位置                                                                                                                                   | 作用                                                                                               |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `@Transactional` | 1、业务（service）层的方法上<br />2、类上（所有方法都交由spring进行事务管理）<br />3、接口（所有实现类）上<br /><br />一般主要还是方法 | 将当前方法交给spring进行事务管理，方法执行前，开启事务；成功执行完毕，提交事务；出现异常，回滚事务 |

一般在业务层控制事务；

可以作用在方法、接口、类上；

开启事务管理日志

```YAML
#开启事务管理日志
logging:
  level:
    org.springframework.jdbc.support.JdbcTransactionManager: debug
```

### Transactional属性

#### rollbackFor

默认情况下，只有出现RuntimeException**运行时异常** 才回滚 。rollbackFor属性用于控制出现何种异常类型，回滚事务；

```Java
// 只要出现异常就回滚
@Transactional(rollbackFor = Exception.class)
```

#### propagation

**事务传播行为** ：当一个事务方法被另一个事务方法调用时，这个事务方法应该如何进行事务控制；

| 属性值            |                                                                                                          |
| ----------------- | -------------------------------------------------------------------------------------------------------- |
| `REQUIRED`      | **默认值** 需要事务，当前有事务则加入，无则创建新事务                                              |
| `REQUIRES_NEW`  | 需要新事务，无论有无，总是创建新事务（即使当前有事务，也是创建一个新的事务）                             |
| `SUPPORTS`      | 支持事务，有则加入，无则在无事务状态中运行                                                               |
| `NOT_SUPPORTED` | 不支持事务，在无事务状态下运行，如果当前存在已有事务，则挂起当前事务（先执行当前，执行完再继续执行事务） |
| `MANDATORY`     | 必须有事务，否则抛异常                                                                                   |
| `NEVER`         | 必须没事务，否则抛异常                                                                                   |

- 无论成功与否都要记录日志的话，用`try-finally`，而且记录日志必须采用`REQUIRES_NEW` 属性值，不然日志记录完会被回滚；
- `REQUIRES_NEW` ： 遇到时，先将当前事务挂起，创建一个新事务，等到新事务执行完再运行挂起的事务；
