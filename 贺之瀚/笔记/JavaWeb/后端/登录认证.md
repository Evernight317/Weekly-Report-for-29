### 会话技术

***会话*** ：浏览器与Web之间的一次连接；用户打开浏览器，访问web服务器的资源，会话建立，直到有一方断开连接，会话结束。在一次会话中可以包含多次请求和响应；

**会话跟踪** ：一种维护浏览器状态的方法，服务器需要识别多次请求是否来自于同一浏览器，以便在同一次会话的多次请求间**共享数据** ；

会话跟踪方案：

- 客户端会话跟踪技术：Cookie
- 服务端会话跟踪技术：Session
- 令牌技术

## 四、Interceptor

一种动态拦截方法调用的机制，类似于过滤器。Spring框架中提供的，用来动态拦截控制器方法的执行；
应用：拦截请求，在指定的方法调用前后，根据业务需要执行预先设定的代码；通常也是做通用操作；

### 入门程序

1. 定义拦截器，实现`HandlerI nterceptor`接口，并重写其所有方法（都有默认实现）；
2. 注册拦截器；

| `preHandler`                                                    | `postHandler`          | `afterCompletion`            |
| ----------------------------------------------------------------- | ------------------------ | ------------------------------ |
| 目标资源方法执行前执行<br />放回true：放行<br />返回false：不放行 | 目标资源方法执行后执行； | 视图渲染完毕后执行，最后执行； |

```Java
// 定义一个配置类，需要加上注解
@Configuration
public class WebConfig implements WebmvcConfiguer {

	@Autowired
  	private 
  
  
  	// 注册拦截器，并且注明所要拦截的资源
  	@Override
  	public void addInterceptor(InterceptorRegistry registry) {
      	registry.addInterceptor().addPathPatterns("/**");
    }
}
```

- 拦截所有，此处应写为`/**` ；

### 拦截路径

- `addPathPatterns` 配置需要拦截的资源；
- `excludePathPatterns` 配置不需要拦截的资源；
- 这两个可以通过*链式编程共同配置*；`addPathPatterns().excludePathPatterns();`

| 拦截路径      |                                  | 能匹配                        | 不能匹配               |
| ------------- | -------------------------------- | ----------------------------- | ---------------------- |
| `/*`        | 一级路径                         | /depts<br />/emps<br />/login | /depts/1               |
| `/**`       | **任意级路径**             |                               |                        |
| `/depts/*`  | /depts下的一级路径               | /depts/1                      | /depts<br />/depts/1/2 |
| `/depts/**` | /depts下的**任意级** 路径 |                               |                        |

### 辨析

Filter与Interceptor区别：

- 接口规范不同：过滤器需要实现Filter接口，而拦截器需要实现HandlerInterceptor接口；
- 拦截范围不同：过滤器Filter会拦截**所有** 的资源，而Interceptor只会拦截**进入Spring环境** 中的资源；

## 五、异常处理-全局异常处理器

遇到异常时，返回的并不是Result，而是错误信息，不符合规范无法被浏览器解析；

解决方法：

- 给每个Controller中的方法写try-catch；
- **全局异常处理器** ；

添加`@RestControllerAdvice`注解在类上，以及注解`@ExceptionHandler(捕获的异常类型)` 在方法上；

```Java
@RestControllerAdvice
public class GlobalExceptionHandler {
  	// 捕获所有异常
  	@ExceptionHandler(Exception.class)
  	public Result ex(Exception ex) {
      	ex.printStackTrace();
      	System.out.println("");
    }
}
```

- `@RestControllerAdvice` =`@ControllerAdvice` +`@ResponseBody`；因此可以自动转换成json响应给前端；
