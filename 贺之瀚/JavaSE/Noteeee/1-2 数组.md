## 一、静态方式

数组内容确定

```Java
int arr[] = {1,2,3};
int arr[] = new int {1,2,3};
```

## 二、动态方式

数组内容待定，仅确定长度、数据类型

```Java
int arr[] = new int [10];
```

java中，数组被视为对象，因此仅有 **堆分配** 一种内存分配方式。同时，java中的数组是在运行期分配内存（与C++动态内存分配一致，不存在静态分配的方式）

## 三、数组的内存分配

具体的值存放在堆中，而栈上保留一个引用变量即数组名，存储的是数组的地址，这样通过数组名即可访问数组

## 四、默认值

不同类型的数组，对应的默认值不同。如 `double` 默认 `0.0` ，`String` 默认 `null`
