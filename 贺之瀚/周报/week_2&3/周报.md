`Java` 学完了OOP和基础的API，具体内容在笔记中，下面列的是一些和 `C++` 差异比较大的地方

```Java
// 输入输出
Scanner sc = new Scanner (System.in);
int tmp = sc.nextInt ();
String tmp = sc.next ();
System.out.print ();
System.out.printf (); // 和C的print很像
System.out.println (); // 输出完后自动换行

// 一切引用类型都必须遵循动态分配的原则
// 即先分配再调用成员方法
// 以数组为例
int arr[] = {1,2,3};
int arr[] = new int [10];

// 变量中，注意byte和boolean
byte tmp = 1; // byte仅有1字节
boolean tmp = true;

// 逻辑表达式中，只能是布尔值的相互比较
if (a%2 == 0)
```
