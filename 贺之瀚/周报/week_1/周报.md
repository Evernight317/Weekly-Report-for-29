## 一、本周学习内容

本周复习了Git相关的操作内容，具体命令笔记放在github上，下面列出一些常用的git操作命令

### git基础配置&SSH配置

SSH有github官方文档（

```Shell
# 配置用户名和邮箱
git config --global user.name"user.name"
git config --global user.email"user.email"
# 查看是否配置成功
git config --global user.name
git config --global user.email
```

### 本地仓库提交到远程仓库及主仓库

```Shell
# 远程仓库Sync Frok后于本地仓库操作
git pull origin main
git add .
git commit -m "这是一个提交"
# 提交到远程仓库
git push origin main 
# 提交pr后merge
```

### 创建本地仓库&查看日志

```Shell
git init

git log --graph --abbrev-commit
git reflog
git reset --hard commitID
```
