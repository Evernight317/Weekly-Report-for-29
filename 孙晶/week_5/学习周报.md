# 学习周报

Maven 基础、SpringBootWeb 请求响应、MyBatis 基础 CRUD 学习

## 一、学习内容

1. Maven 与 SpringBootWeb 基础

- 复习 Maven 依赖管理，熟练使用 Maven 管理 SpringBoot 项目依赖，理解 Lombok 工具包作用，使用 @Data、@NoArgsConstructor、@AllArgsConstructor 简化实体类开发，减少模板代码。
- 掌握 Apifox 接口测试工具，练习各类请求参数接收：`@PathVariable`接收路径参数，`@RequestParam`接收`?`后的查询参数，分清两种注解使用场景、区别以及省略条件。
- 掌握三层架构：Controller 控制层接收请求、Service 处理业务、Mapper 层操作数据库，理解分层职责，使用 IOC、DI 完成对象注入，降低代码耦合。

2.MyBatis 基础

- 了解 MyBatis 作用：简化 JDBC 操作，省去手动获取连接、关闭连接、手动封装结果集等重复代码；认识数据库连接池，对比传统 JDBC，理解连接池复用连接、提升性能的优势。
- 掌握 MyBatis 环境搭建，完成 application.properties 数据库连接配置，配置驼峰命名自动映射，解决数据库下划线字段与 Java 实体驼峰属性映射问题。
- 学习 MyBatis 注解开发，完成基础 CRUD：新增、删除、修改、根据 ID 查询；掌握新增操作**主键返回**`useGeneratedKeys`、`keyProperty`，实现自增主键回填到实体对象。
- 学习条件查询，实现多条件动态筛选数据；区分物理外键与逻辑外键，理解多对多关系中间表设计。
- 了解 MyBatis 日志配置，学习配置控制台 SQL 输出，方便调试查看执行的 SQL 语句，理解`StdOutImpl`日志实现带来的日志输出冲突问题。

3.MyBatis 进阶预习

- 了解 XML 映射文件开发方式；初步接触动态 SQL，认识`<if>`、`<foreach>`标签，用于拼接灵活多变的查询 SQL。

## 二、遇到难题解决方法

1. 问题：分不清`@PathVariable`和`@RequestParam`，参数接收拿不到数据，出现 400、404 报错

   解决：记忆区分，大括号`{}`路径占位符使用`@PathVariable`，不可省略；url 问号后参数使用`@RequestParam`，参数名一致可以省略。遇到 400 报错优先检查参数是否必填、参数类型是否匹配。

2. 问题：数据库字段带下划线，实体类驼峰属性，查询结果部分字段封装为 null

   解决：开启 MyBatis 配置`map‑underscore‑to‑camel‑case=true`驼峰自动映射，也可以使用`@Results`手动映射字段。

3. 问题：主键返回不生效，新增数据之后实体拿不到自增 id

   解决：确认`useGeneratedKeys=true`只支持 MySQL 自增主键；`keyProperty`的值必须和 Java 实体类属性名完全一致，不是数据库字段名。

## 三、本周总结

本周学习 MyBatis 持久层框架，摆脱原生 JDBC 繁琐代码，实现后端程序和 MySQL 数据库交互。熟练完成 MyBatis 注解方式 CRUD 增删改查，掌握主键回填、驼峰映射、SQL 日志调试。

巩固 SpringBootWeb 接口开发，分清两种参数接收注解，理解三层架构各层分工。打通完整流程：浏览器发送 HTTP 请求→Controller 接收参数→Service 处理业务→Mapper 访问数据库，数据库结果反向封装返回给前端。同时踩过日志冲突、字段映射失败、参数接收报错等问题，积累调试排错经验。
