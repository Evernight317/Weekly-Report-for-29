# 学习周报

Java多线程、注解与反射、动态代理、AOP、SpringBoot高级原理学习

## 一、学习内容

### 1. Java 多线程基础与并发

系统学习多线程核心知识点，掌握线程新建、就绪、运行、阻塞、终止五大生命周期，区分并发与并行的核心区别，重点掌握线程安全解决方案、线程通信、线程池、乐观锁核心框架与使用规范。

**1）线程安全与 synchronized 同步锁**

核心作用：解决多线程并发操作共享变量的数据错乱问题，保证线程操作的原子性、可见性、有序性。支持两种使用方式：同步代码块、同步方法。核心要点：必须使用多线程共享的锁对象，局部变量锁无法实现同步效果。

**2）线程等待唤醒机制**

核心方法：wait()、notify()、notifyAll()，通过线程等待与唤醒实现多线程协作，避免空轮询占用CPU资源，理解生产者消费者模型的底层实现逻辑。

**3）线程池核心框架**

核心作用：复用线程资源，避免频繁创建、销毁线程造成的性能损耗。掌握线程池五大核心参数：核心线程数、最大线程数、空闲线程存活时间、阻塞队列、拒绝策略。区分 `Executors` 工具类快速创建线程池与原生 `ThreadPoolExecutor` 手动创建线程池的适用场景。

### 2. 注解、反射、动态代理

**1）反射机制核心框架**

核心原理：程序运行阶段动态获取类的字节码信息，动态创建对象、操作属性、调用方法，是主流框架底层核心原理。掌握三种获取Class字节码对象的方式，支持操作公有、私有类成员。关键要点：操作私有构造器、属性、方法时，需开启**暴力反射**（setAccessible(true)）关闭权限检查。

**2）自定义注解框架**

掌握两大核心元注解：**@Target**（限定注解作用位置：类、方法、字段等）、**@Retention**（限定注解生命周期：源码、编译、运行阶段）。可自定义功能注解，结合反射技术在运行时解析注解信息，实现自定义功能拓展。

**3）JDK 动态代理核心原理**

核心特点：基于接口实现，无需修改目标类原有代码，即可对目标方法进行前置、后置功能增强，是Spring AOP的底层实现原理。核心逻辑：通过代理对象拦截目标方法执行，自定义增强逻辑，实现代码解耦。

### 3. Spring AOP 面向切面编程

核心思想：面向切面编程，实现业务代码与通用公共功能解耦，无侵入式增强目标方法，常用于日志记录、权限校验、事务控制等场景。

**1）核心注解框架**

@Aspect：标识当前类为切面类；@Component：将切面类交由Spring容器管理；@Pointcut：定义切入点，匹配需要增强的目标方法。

**2）五大通知类型（执行时机）**

@Before前置通知、@AfterReturning后置正常通知、@AfterThrowing异常通知、@After最终通知、@Around环绕通知（功能最全，可手动控制目标方法执行）。

**3）切入点表达式**

掌握execution通用表达式语法，通过包名、类名、方法名、参数通配符，精准匹配需要增强的目标方法，实现精准切面拦截。

### 4. SpringBoot 核心配置与Bean管理

**1）Bean 管理核心注解**

@Configuration：标识配置类；@Bean：将第三方类注册为Spring容器Bean，实现第三方资源托管。掌握Bean单例、多例作用域配置与使用场景。

**2）SpringBoot 自动配置原理**

掌握yml、properties配置文件加载优先级，理解starter起步依赖自动导入依赖、条件注解自动装配Bean的核心逻辑，明白SpringBoot零配置简化开发的底层原理。

## 二、遇到难题解决方法

问题1：多线程添加同步锁后，依旧存在线程安全问题

解决：排查锁对象有效性，必须使用多线程共享的全局对象作为锁，禁止使用局部变量；区分volatile和synchronized区别，volatile仅保证可见性，无法保证原子性，数据更新操作必须使用同步锁。

问题2：反射操作私有类成员，抛出权限访问异常

解决：所有私有构造器、成员变量、成员方法的反射操作，必须手动开启暴力反射 setAccessible(true)，关闭Java权限校验机制。

问题3：自定义AOP切面不生效，通知逻辑无法执行

解决：确认切面类同时添加 @Aspect 和 @Component 注解，确保被Spring容器扫描管理；核对切入点表达式，保证包路径、方法匹配规则无误。
