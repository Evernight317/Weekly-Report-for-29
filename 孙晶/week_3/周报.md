# html5

## 基础认知

网页由哪些部分组成？**文字、图片、音频、视频、超链接**

网页背后本质是什么？**前端程序员写的代码**

**前端代码通过浏览器转化（解析和渲染）成用户看到的网页**

**渲染引擎（浏览器内核）**：浏览器中专门对代码进行解析渲染的部分

**Web标准**：不同的浏览器的渲染引擎不同，对于相同的代码解析的效果存在差异，Web标准让不同的浏览器按照相同的标准显示结果，让展示的效果统一！

# CSS

## 基础认知

CSS给页面的HTML标签设置样式

写在style标签中，style标签一般写在head标签里面，title标签下面

## CSS引入方式

![880c33a880bbe25e32815896991589c5](C:\Users\PC\Documents\Tencent Files\3631076978\nt_qq\nt_data\Pic\2026-07\Ori\880c33a880bbe25e32815896991589c5.jpg)

~~~html
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>
        /* 内嵌式 */
        p {
            /* 文字颜色 */
            color:red ;
            /* 字体大小 px：像素 */
            font-size: 30px;
            /* 背景颜色 */
            background-color: aqua;
            width: 400px;
            height: 400px;
        }
    </style>
</head>
<body>
    <p>这是一个p标签</p> 
</body>
~~~

~~~html
<!-- 外联式stylesheet关系为样式表 -->
    <link rel="stylesheet" href="./my.css">
~~~

~~~html
<!-- 行内式 -->
    <div style="color: aqua; font-size: 30px;">这是div标签</div>
~~~
