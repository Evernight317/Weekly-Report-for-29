## 一、学习内容

### 1.Redis 的 Java 客户端开发

1）Jedis 原生客户端 引入 Jedis 的 Maven 依赖，创建 Jedis 对象指定 Redis 服务 IP、端口、密码建立连接。

```java
//建立连接
Jedis jedis = new Jedis("192.168.126.100",6379);
jedis.auth("123456");
//String操作
jedis.set("user:1001:name","zhangsan");
String name = jedis.get("user:1001:name");
//批量操作
jedis.mset("user:1002:name","lisi","user:1002:age","22");
List<String> list = jedis.mget("user:1002:name","user:1002:age");
jedis.close();
```

学习 Jedis 连接池`JedisPool`，配置最大连接数、空闲连接，复用连接对象，避免频繁创建销毁连接造成性能消耗。

2）SpringBoot 整合 RedisTemplate 导入 spring‑boot‑starter‑redis 依赖，在**application.properties**配置 redis 服务地址端口密码。

```java
# redis连接配置
spring.redis.host=192.168.126.100
spring.redis.port=6379
spring.redis.password=123
```

原生 RedisTemplate 默认使用 JDK 序列化，存入 redis 会出现`\xac\xed\x00\x05t\x00`乱码前缀。编写配置类，替换 key、value 序列化器为`Jackson2JsonRedisSerializer`。

```java
@Configuration
public class RedisConfig {
    @Bean
    public RedisTemplate<String,Object> redisTemplate(RedisConnectionFactory factory){
        RedisTemplate<String,Object> template = new RedisTemplate<>();
        template.setConnectionFactory(factory);
        Jackson2JsonRedisSerializer<Object> jsonSer = new Jackson2JsonRedisSerializer<>(Object.class);
        //设置key序列化
        template.setKeySerializer(RedisSerializer.string());
        template.setValueSerializer(jsonSer);
        template.afterPropertiesSet();
        return template;
    }
}
```

注入 RedisTemplate 完成 String 类型读写：

```java
@Autowired
private RedisTemplate<String,Object> redisTemplate;
redisTemplate.opsForValue().set("user:1003:name","wangwu",30, TimeUnit.SECONDS);
Object val = redisTemplate.opsForValue().get("user:1003:name");
```

### 2.MyBatis‑Plus 框架学习

1）快速入门与注解配置 引入 mybatis‑plus‑spring‑boot‑starter 依赖，编写实体 User，使用 MP 注解映射数据库表。

```java
@TableName("tb_user") //指定对应数据库表名
public class User {
    @TableId(type = IdType.AUTO) //主键自增
    private Long id;
    @TableField("user_name") //数据库字段和实体属性不一致手动映射
    private String userName;
    private Integer age;
}
```

Mapper 接口继承`BaseMapper<User>`，直接拥有内置 CRUD 方法，不需要写 xml：

```java
@Mapper
public interface UserMapper extends BaseMapper<User> {
}
```

在 application.properties 配置打印 SQL 日志、全局表前缀、开启下划线转驼峰：

```java
#MyBatis‑Plus全局配置
mybatis-plus.global-config.db-config.table-prefix=tb_
mybatis-plus.global-config.db-config.id-type=auto
#打印执行SQL日志
mybatis-plus.configuration.log-impl=org.apache.ibatis.logging.stdout.StdOutImpl
#开启下划线转驼峰映射
mybatis-plus.configuration.map-underscore-to-camel-case=true
```

2）条件构造器 QueryWrapper、LambdaQueryWrapper 普通 QueryWrapper，手写字段名，实现条件查询：

```java
//查询age>18，user_name包含"张"，按id降序
QueryWrapper<User> wrapper = new QueryWrapper<>();
wrapper.gt("age",18)
       .like("user_name","张")
       .orderByDesc("id");
List<User> users = userMapper.selectList(wrapper);
```

LambdaQueryWrapper，使用实体 getter，避免字符串字段拼写错误：

```java
LambdaQueryWrapper<User> lambdaWrapper = Wrappers.lambdaQuery();
lambdaWrapper.gt(User::getAge,18).like(User::getUserName,"张");
List<User> list = userMapper.selectList(lambdaWrapper);
```

3）自定义 SQL 当 BaseMapper 方法不够用，Mapper 接口定义抽象方法：

```java
@Mapper
public interface UserMapper extends BaseMapper<User> {
    List<User> selectUserByAge(@Param("age") Integer age);
}
```

在 xml 文件写原生 MyBatis SQL：

```java
<select id="selectUserByAge" resultType="com.entity.User">
    select * from tb_user where age > #{age}
</select>
```

4）IService 业务层接口 Service 接口继承`IService<User>`

```java
public interface UserService extends IService<User> {
}
```

实现类继承`ServiceImpl<UserMapper,User>`，ServiceImpl 已经封装大量业务层 CRUD 方法。

```java
@Service
public class UserServiceImpl extends ServiceImpl<UserMapper, User> implements UserService {
}
```

测试 IService 基础 CRUD、Lambda 查询、批量新增：

```java
//lambda查询
userService.lambdaQuery().gt(User::getAge,18).list();
//批量新增
List<User> batchList = new ArrayList<>();
batchList.add(new User(null,"张三",20));
batchList.add(new User(null,"李四",21));
//批量插入
userService.saveBatch(batchList);
```

## 二、遇到难题解决方法

问题 1：RedisTemplate 存入数据，Redis 客户端查看 key 出现一串乱码前缀。

 解决：默认 JDK 序列化会把对象序列化二进制存储，造成 key 可读性差。新建 RedisConfig 配置类，使用`Jackson2JsonRedisSerializer`替换默认序列化器，设置 key 使用字符串序列化，存入 redis 的 key、value 展示正常可读。

问题 2：MyBatis‑Plus 实体类属性名和数据库表字段名不一致，查询返回字段数据为 null。 

解决：方案一，实体属性上加`@TableField(value="数据库字段名")`做字段映射；方案二，在 application.properties 配置开启`mybatis‑plus.configuration.map‑underscore‑to‑camel‑case=true`，开启下划线自动转驼峰，自动映射数据库字段与实体属性。
