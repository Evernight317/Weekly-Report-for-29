# 苍穹外卖项目后端总结

## 一、项目概述

苍穹外卖是一款面向社区/校园场景的**企业级外卖平台（B2C 模式）**，包含两个业务端：**管理端**（PC Web，供商家运营）与**用户端**（微信小程序，供消费者点餐）。后端基于 **Spring Boot 单体多模块架构**开发，统一对外提供 RESTful API，覆盖员工管理、菜品/套餐管理、购物车、订单、支付、统计报表等完整外卖业务闭环。

## 二、技术栈

| 分类 | 技术 |
| ---- | ---- |
| 基础框架 | Spring Boot 2.7.3、Maven 多模块 |
| 持久层 | MyBatis（XML 动态 SQL）、MySQL 8、Druid 连接池、PageHelper 分页 |
| 缓存 | Redis、Spring Cache |
| 安全认证 | JWT（jjwt）、HandlerInterceptor 双端拦截器 |
| 定时任务 | Spring Task（@Scheduled） |
| 实时通信 | WebSocket |
| 接口文档 | Knife4j（Swagger） |
| 文件存储 | 阿里云 OSS |
| 支付 | 微信支付 APIv3（JSAPI 下单、回调、退款） |
| 报表 | Apache POI（Excel 导出） |
| 其他 | Lombok、fastjson、AOP（AspectJ）、HttpClient、多环境配置 |

## 三、后端工程结构（Maven 多模块）

| 模块 | 职责 | 主要内容 |
| ---- | ---- | ---- |
| **sky-common** | 通用基础模块 | 统一返回结果 Result/PageResult、统一异常体系（BaseException 及业务子类）、常量类、JwtUtil/AliOssUtil/WeChatPayUtil/HttpClientUtil 工具类、BaseContext（ThreadLocal 上下文）、JwtProperties/AliOssProperties/WeChatProperties 配置属性类 |
| **sky-pojo** | 数据模型模块 | entity（对应 11 张表的实体类）、dto（请求参数对象）、vo（响应视图对象） |
| **sky-server** | 核心服务模块 | controller（admin/user 双端）、service 及 impl、mapper（接口 + XML）、config、interceptor、aspect、handler、task、websocket、annotation |

分层设计：**Controller（表现层）→ Service（业务层）→ Mapper（数据层）**，每层职责单一；DTO/VO 与实体分离，前端请求参数不直接绑定数据库实体，避免接口暴露表结构。

## 五、数据库设计

共 **11 张表**，分为三类：

- **基础信息**：employee（员工）、category（分类）、dish（菜品）、dish_flavor（菜品口味）、setmeal（套餐）、setmeal_dish（套餐-菜品关系）
- **用户侧**：user（用户）、address_book（地址簿）、shopping_cart（购物车）
- **交易侧**：orders（订单）、order_detail（订单明细）

设计要点：

1. **逻辑外键**：表间关联不建物理外键，由业务层保证一致性，提升写入性能与扩展性。
2. **合理冗余**：订单表冗余收货人/地址/用户姓名等快照字段，防止地址变更影响历史订单；setmeal_dish 冗余菜品名与单价，减少联表查询。
3. **状态枚举化**：orders.status 六态（1 待付款、2 待接单、3 已接单、4 派送中、5 已完成、6 已取消），pay_status 三态（0 未支付、1 已支付、2 退款）。
4. **公共审计字段**：各业务表统一维护 create_time/update_time/create_user/update_user，配合 AOP 自动填充。

## 六、核心技术

1. **统一返回 + 全局异常处理**：所有接口返回 Result<T> 统一封装；GlobalExceptionHandler 兜底所有异常，业务异常统一继承 BaseException，错误信息前端可读。
2. **双端 JWT 认证**：管理端/用户端使用独立密钥与过期时间，分别由 JwtTokenAdminInterceptor / JwtTokenUserInterceptor 拦截校验；登录用户信息存入 BaseContext（ThreadLocal）随请求传递，避免层层传参。
3. **AOP 公共字段自动填充**：自定义 @AutoFill 注解 + AutoFillAspect 切面，在 insert/update 时自动维护四个公共审计字段，消除大量重复代码。
4. **Redis 缓存**：店铺营业状态实时读写 Redis；菜品/套餐列表通过 Spring Cache（@Cacheable/@CacheEvict）缓存，数据变更自动失效，减轻数据库压力。
5. **定时任务保障订单闭环**：OrderTask 每分钟扫描超过 15 分钟未支付的订单自动取消；每日凌晨 1 点将长时间处于派送中的订单自动置为已完成。
6. **WebSocket 实时推送**：新订单/用户催单通过 WebSocketServer 实时推送到管理端，配合前端弹窗和语音提醒，提升接单及时性。
7. **微信支付集成**：基于微信支付 APIv3 实现 JSAPI 下单、支付结果回调验签、退款，覆盖支付完整链路。
8. **报表导出**：Apache POI 生成近 30 天营业数据 Excel 报表（按 10 天一组，5 周），支持管理端一键下载。
9. **文件上传**：图片统一上传阿里云 OSS，数据库仅存 URL，支持 CDN 扩展。
10. **多环境与配置外置**：application.yml + application-dev.yml 分环境配置，数据库、Redis、OSS、微信支付等敏感参数通过 ${} 占位注入，便于部署切换。
