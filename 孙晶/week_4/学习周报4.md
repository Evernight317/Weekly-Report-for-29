# 学习周报

Maven 项目管理、JavaWeb 入门、HTTP 协议、Tomcat、请求响应、三层架构与 IOC/DI 基础学习

## 一、学习内容

1. Maven

- 掌握 Maven 作用：项目构建、依赖管理、统一项目结构；完成本地 Maven 安装，在 IDEA 中完成环境集成，配置阿里云镜像加速依赖下载。
- 学习 pom.xml 依赖配置，理解依赖坐标（groupId、artifactId、version），掌握依赖传递、依赖冲突、依赖范围（compile/test/provided/runtime）。
- 熟悉 Maven 生命周期：clean、compile、test、package、install 等常用阶段命令。

2.Web 入门 & HTTP 协议

- 理解 BS 架构：浏览器为客户端，服务端提供资源，依靠 HTTP 协议通信。
- HTTP 概念：超文本传输协议，基于 TCP，无状态协议；学习 HTTP 请求报文、响应报文结构。
- 区分 GET 与 POST 请求特点，了解常见响应状态码，掌握 HTTP 协议通信完整流程。

3.Tomcat 

- 认识 Tomcat 作用：Web 容器，负责接收浏览器 HTTP 请求，调用 Java 代码并返回响应。
- 学习 Tomcat 基础使用，理解端口配置、项目部署方式，结合 SpringBoot 内置 Tomcat 运行 web 项目。

4.请求与响应（SpringBoot Web）

- 使用 Postman 进行接口测试，掌握接收各类请求参数：普通参数、数组、集合、日期参数、路径参数。
- 学习响应处理，使用 @ResponseBody 返回 JSON 数据，完成基础前后端数据交互案例。

5.分层解耦、IOC & DI

- 学习三层架构：Controller（控制层）、Service（业务层）、Mapper（数据访问层），实现代码分层，职责拆分。
- 理解传统 new 对象方式耦合严重问题，学习 IOC（控制反转）、DI（依赖注入）核心思想。
- 掌握 IOC 容器作用：由容器创建管理对象，DI 实现对象依赖自动注入，初步实现代码解耦。

## 二、遇到难题解决方法

1. 问题：IDEA 中 Maven 依赖下载缓慢、部分 jar 包下载失败

   解决：修改 maven 的 settings.xml 配置阿里云镜像源，清理本地仓库失效文件，重新刷新 Maven 项目。

2. 问题：HTTP 概念分不清客户端、服务端，请求 / 响应流程理解模糊

   解决：画图梳理浏览器与服务器通信流程，结合浏览器 F12 开发者工具 Network 面板观察真实 http 请求报文，对照课程案例逐段分析。

3. 问题：接收前端日期格式参数时报类型转换异常

   解决：使用 @DateTimeFormat 注解指定日期格式，统一前后端日期传输格式。

4. 问题：三层架构代码耦合高，不理解 IOC 为什么能解耦

   解决：先手写传统 new 方式代码感受耦合痛点；再对比 IOC 容器托管对象写法，理清 “主动创建对象” 转变为 “容器提供对象” 的核心区别。

## 三、本周总结

本周系统学习 JavaWeb 前置基础：从 Maven 项目管理工具入手，搭建开发环境；接着学习 BS 架构、HTTP 通信协议、Tomcat 服务器；然后基于 SpringBoot Web 学习接口请求参数接收、JSON 响应开发；最后接触分层架构思想与 Spring IOC/DI 核心原理。

已经打通浏览器访问后端服务的完整链路，理解客户端发起 HTTP 请求，服务端接收请求、执行业务、返回响应整套流程。
