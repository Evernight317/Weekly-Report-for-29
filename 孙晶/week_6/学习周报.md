# 学习周报

Linux 操作系统基础、Redis 基础入门学习（没学完）

## 一、学习内容

1. Linux 操作系统基础

- 搭建 Linux 练习环境，使用虚拟机部署 centos系统，掌握 FinalShell 远程连接工具，实现本地终端远程操控服务器，理解 SSH 远程连接原理。
- 熟悉 Linux 文件体系结构，区分根目录 `/`、家目录，掌握绝对路径、相对路径概念，熟练使用`cd`、`pwd`切换与查看当前目录。
- 掌握基础文件命令：`ls`查看目录文件与权限、`mkdir`创建文件夹、`touch`新建文件、`cp`复制、`mv`移动 / 重命名、`rm`删除文件与目录；学会`cat`、`more`查看文件内容。
- 学习文本编辑器 vi/vim 操作，熟记普通模式、插入模式、底线模式切换；掌握文件编辑、保存`:wq`、强制退出不保存`:q!`等常用指令。
- 学习权限基础概念，读懂`ls -l`输出的权限字符串，理解文件所有者、所属组、其他用户三类权限；初步学习`chmod`修改文件权限。
- 使用`which`、`find`实现系统命令查找、磁盘文件检索；学习管道符`|`、`grep`过滤筛选文本内容；利用`echo`、`tail`、输出重定向完成日志读写操作。
- 了解系统用户机制，区分普通用户与 root 超级管理员，掌握`sudo`临时提升权限执行受限命令，解决文件创建、修改权限不足问题。

2.Redis 基础入门

- 认识 NoSQL 非关系型数据库，对比 MySQL 关系型数据库，理解 Redis 内存数据库特性、高性能适用场景。
- Redis 编译安装，修改`redis.conf`核心配置文件：配置后台守护进程`daemonize yes`，设置 RDB 持久化文件存储目录，解决持久化保存权限报错问题。
- 掌握 Redis 启动三种方式：前台直接启动、后台守护进程启动、指定配置文件启动；学习优雅关闭`redis-cli shutdown`，杜绝强制杀进程丢失数据。
- 使用 redis-cli 客户端连接服务，学习 Redis 通用命令：`keys`查看键、`del`删除键、`exists`判断 key 是否存在、`expire`设置过期时间。
- 学习 Redis 最常用 String 字符串数据类型，掌握`set`、`get`、`mset`、`mget`批量操作；理解 key 层级命名规范，使用冒号`:`实现业务数据分类管理。
- 了解 Redis 图形化客户端连接方式，学习使用可视化工具便捷查看库内数据。

## 二、遇到难题解决方法

1. 问题：在`/usr/local/src`目录下直接启动 Redis，权限不足，按下 Ctrl+C 无法退出，只能新开终端杀进程；切换至普通目录启动就可以正常使用 Ctrl+C 终止程序。

   解决：`/usr/local/src`属于系统目录，普通用户权限受限，Redis 进程收到中断信号处理异常，导致 Ctrl+C 失效。不要直接在系统高阶目录运行程序，切换到用户拥有完整权限的目录启。

2. 问题：CentOS 7 系统停止维护，软件源不可用，依赖包无法下载，Redis 编译安装失败

   解决：CentOS7 生命周期结束，官方源下线，很多依赖库找不到安装包。更换为 Ubuntu 系统，软件源更新活跃，依赖安装顺畅，顺利完成 Redis 编译部署。后续学习优先选用仍在支持维护的发行版。
