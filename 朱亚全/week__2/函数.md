# MySQL 函数全面总结

---

## 1. 字符串函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `CONCAT(str1, str2, ...)` | 拼接多个字符串 | `CONCAT('Hello', ' ', 'World')` → `'Hello World'` |
| `LOWER(str)` | 转小写 | `LOWER('ABC')` → `'abc'` |
| `UPPER(str)` | 转大写 | `UPPER('abc')` → `'ABC'` |
| `LPAD(str, n, pad)` | 左填充，使字符串达到 n 位 | `LPAD('123', 5, '0')` → `'00123'` |
| `RPAD(str, n, pad)` | 右填充，使字符串达到 n 位 | `RPAD('123', 5, '0')` → `'12300'` |
| `TRIM(str)` | 去除首尾空格 | `TRIM('  Hello  ')` → `'Hello'` |
| `SUBSTRING(str, start, n)` | 截取字符串，**起始索引从 1 开始** | `SUBSTRING('Hello', 2, 3)` → `'ell'` |

### 示例

```sql
-- 查看数据
SELECT * FROM emp;

-- 将 id 左填充到 6 位，不足用 2 填充
UPDATE emp SET id = LPAD(id, 6, 2);
```

## 2. 数值函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `CEIL(x)` | 向上取整 | `CEIL(3.14)` → `4` |
| `FLOOR(x)` | 向下取整 | `FLOOR(3.99)` → `3` |
| `MOD(x, y)` | 取模（取余数） | `MOD(10, 3)` → `1` |
| `RAND()` | 返回 0~1 之间的随机数 | `RAND()` → `0.123456...` |
| `ROUND(x, n)` | 四舍五入，保留 n 位小数 | `ROUND(3.14159, 2)` → `3.14` |

### 示例

```sql
-- 生成 6 位随机数字，左补 0
SELECT LPAD(ROUND(RAND() * 1000000, 0), 6, '0');

-- 左填充测试
SELECT LPAD(200, 5, '-');  -- 结果：'--200'
```

## 3. 日期函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `CURDATE()` | 返回当前日期 | `CURDATE()` → `'2026-08-06'` |
| `CURTIME()` | 返回当前时间 | `CURTIME()` → `'14:30:25'` |
| `NOW()` | 返回当前日期和时间 | `NOW()` → `'2026-08-06 14:30:25'` |
| `YEAR(date)` | 提取年份 | `YEAR('2026-08-06')` → `2026` |
| `MONTH(date)` | 提取月份 | `MONTH('2026-08-06')` → `8` |
| `DAY(date)` | 提取日 | `DAY('2026-08-06')` → `6` |
| `DATE_ADD(date, INTERVAL expr type)` | 日期增加 | `DATE_ADD(NOW(), INTERVAL 2 DAY)` |
| `DATE_SUB(date, INTERVAL expr type)` | 日期减少 | `DATE_SUB(NOW(), INTERVAL 2 DAY)` |
| `DATEDIFF(date1, date2)` | 计算日期差（date1 - date2） | `DATEDIFF('2025-01-01', '2026-02-01')` |

### 示例

```sql
-- 获取当前月份
SELECT MONTH(NOW());

-- 当前日期加 2 天
SELECT DATE_ADD(NOW(), INTERVAL 2 DAY);

-- 计算两个日期的天数差
SELECT DATEDIFF('2025-01-01', '2026-02-01');

-- 查询每个员工的入职天数（从入职到当前）
SELECT name, DATEDIFF(CURDATE(), time) AS 'days' FROM emp ORDER BY days DESC;
```

## 4. 流程函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `IF(value, t, f)` | 三元运算符，value 为真返回 t，否则返回 f | `IF(1 > 2, 'OK', 'Error')` → `'Error'` |
| `IFNULL(value1, value2)` | value1 为 NULL 返回 value2，否则返回 value1 | `IFNULL(NULL, 1)` → `1` |
| `CASE 字段 WHEN 值 THEN 结果 END` | 等值判断 | 见下方示例 |
| `CASE WHEN 条件 THEN 结果 END` | 范围/复杂条件判断 | 见下方示例 |

### 示例

```sql
-- IF 函数示例
SELECT IF(1 > 2, 'OK', 'Error');   -- 结果：Error
SELECT IF(1 < 2, 'OK', 'Error');   -- 结果：OK

-- IFNULL 函数示例
SELECT IFNULL('OK', 'Error');      -- 结果：OK
SELECT IFNULL(NULL, 1);            -- 结果：1

-- CASE 等值判断：查询员工姓名和工作城市等级
SELECT 
    name,
    CASE address 
        WHEN '北京' THEN '一线城市' 
        WHEN '上海' THEN '一线城市' 
        ELSE '二线城市' 
    END AS '工作城市'
FROM emp;
```

## 5. 综合案例：学生成绩表

### 5.1 创建表

```sql
CREATE TABLE stu (
    name VARCHAR(20) COMMENT '姓名',
    class CHAR(4) COMMENT '班级',
    gender CHAR(1) COMMENT '性别',
    chinese TINYINT UNSIGNED COMMENT '语文成绩',
    math TINYINT UNSIGNED COMMENT '数学成绩',
    english TINYINT UNSIGNED COMMENT '英语成绩',
    physics TINYINT UNSIGNED COMMENT '体育成绩',
    chemistry TINYINT UNSIGNED COMMENT '化学成绩',
    biology TINYINT UNSIGNED COMMENT '生物成绩'
) COMMENT '学生成绩表';
```

### 5.2 插入数据

```sql
INSERT INTO stu (name, class, gender, chinese, math, english, physics, chemistry, biology) VALUES
('张三', '高一1班', '男', 85, 92, 78, 88, 91, 84),
('李四', '高一1班', '女', 92, 76, 89, 93, 77, 90),
('王五', '高一2班', '男', 68, 95, 72, 65, 88, 70),
('赵六', '高一2班', '女', 79, 88, 94, 72, 83, 91),
('孙七', '高一1班', '男', 96, 81, 87, 79, 94, 82),
('周八', '高一3班', '女', 73, 67, 81, 85, 69, 78),
('吴九', '高一2班', '男', 45, 52, 38, 40, 55, 48),
('郑十', '高一3班', '男', 88, 91, 86, 90, 87, 89);
```

### 5.3 查询示例（使用流程函数）

```sql
-- 查看所有数据
SELECT * FROM stu;

-- 查询：姓名、性别代号（男=1，女=0）、语文等级、数学等级
SELECT 
    name AS '姓名',
    CASE gender
        WHEN '男' THEN 1
        ELSE 0
    END AS '性别代号',
    CASE 
        WHEN chinese >= 85 THEN '优秀'
        WHEN chinese >= 60 THEN '及格'
        ELSE '不及格'
    END AS '语文',
    CASE 
        WHEN math >= 90 THEN '优秀'
        WHEN math >= 60 THEN '及格'
        ELSE '不合格'
    END AS '数学'
FROM stu;
```
