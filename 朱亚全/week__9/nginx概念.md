# Nginx 概述

> Nginx 是一个高性能的 HTTP 和反向代理服务器，常作为前端与后端之间的中间层。

---

## 一、Nginx 是什么

**Nginx：中间层服务器，站在浏览器和后端之间。**

### 核心职责

- **派发前端静态文件**（HTML / CSS / JS）
- **把 API 请求转发给后端**
- **解决页面刷新 404、跨域等问题**

### 好处

| 能力 | 说明 |
|------|------|
| **缓存** | 缓存静态资源，减轻后端压力 |
| **负载均衡** | 把请求分发到多台后端服务器 |
| **保护后端安全** | 后端不直接暴露，由 Nginx 统一入口 |

---

## 二、正向代理 vs 反向代理

| 对比项 | 正向代理 | 反向代理 |
|--------|----------|----------|
| **代表** | 翻墙、公司内网访问外网 | Nginx |
| **客户端知道吗** | ✅ 知道自己在用代理 | ❌ 不知道 |
| **部署位置** | 客户端这边 | 服务器这边 |

> **核心：看代理服务器部署在谁的地盘上。**

```text
正向代理：
客户端 → [代理] → 服务器
         ↑
      客户端知道

反向代理：
客户端 → [代理] → 服务器
         ↑
      客户端不知道，以为直接访问服务器
```

# Nginx 学习路径

> 按角色和深度划分三个阶段：入门（开发必会）、进阶（后端/运维）、高级（运维/架构）。

---

## 一、入门（开发必会）

```text
入门（开发必会）
  ├── 安装与启动
  ├── 静态文件服务
  ├── 反向代理 proxy_pass
  ├── 解决跨域
  └── 解决刷新 404（try_files）
```

| 知识点 | 说明 |
|--------|------|
| **安装与启动** | Windows 双击 `nginx.exe`，Linux 用 `yum` / `apt`；常用命令 `nginx -s reload`、`nginx -s stop` |
| **静态文件服务** | 用 `root` / `alias` 指定前端打包目录，`index` 指定默认首页 |
| **反向代理 proxy_pass** | 把 `/api` 请求转发到后端服务，如 `proxy_pass http://localhost:8080/;` |
| **解决跨域** | 前端与后端同源由 Nginx 统一入口，或配置 `add_header Access-Control-Allow-Origin` |
| **解决刷新 404（try_files）** | SPA 应用刷新路由时返回 `index.html`，配置 `try_files $uri $uri/ /index.html;` |

---

## 二、进阶（后端/运维）

```text
进阶（后端/运维）
  ├── 负载均衡 upstream
  ├── 缓存 proxy_cache
  ├── gzip 压缩
  ├── HTTPS 配置
  └── 日志分析
```

| 知识点 | 说明 |
|--------|------|
| **负载均衡 upstream** | 定义后端服务器组，支持轮询、权重、IP Hash、最少连接等策略 |
| **缓存 proxy_cache** | 缓存后端响应，减少回源，提升响应速度 |
| **gzip 压缩** | 压缩传输内容，减少带宽，提升加载速度 |
| **HTTPS 配置** | 配置 SSL 证书，实现 HTTPS 加密访问 |
| **日志分析** | 分析 `access.log` / `error.log`，排查问题、统计流量 |

---

## 三、高级（运维/架构）

```text
高级（运维/架构）
  ├── 性能调优
  ├── 高可用（Keepalived）
  ├── 限流与防攻击
  ├── 动态 upstream（Consul / Nacos）
  └── 与网关配合
```

| 知识点 | 说明 |
|--------|------|
| **性能调优** | 调整 `worker_processes`、`worker_connections`、`keepalive_timeout` 等参数 |
| **高可用（Keepalived）** | Nginx 主备切换，配合虚拟 IP 实现故障自动转移 |
| **限流与防攻击** | 用 `limit_req`、`limit_conn` 限流，防 DDoS、防爬虫 |
| **动态 upstream（Consul / Nacos）** | 服务注册发现，后端节点动态上下线，无需手动改配置 |
| **与网关配合** | 与 Spring Cloud Gateway、Kong 等网关协同，Nginx 负责入口层，网关负责业务路由 |
