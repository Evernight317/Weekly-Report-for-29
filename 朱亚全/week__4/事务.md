# MySQL 事务全面总结

## 1. 事务基本概念

**事务（Transaction）** 是一组原子性的 SQL 操作单元，要么全部执行成功，要么全部失败回滚。

---

## 2. 事务控制语句

```sql
-- 方式一：关闭自动提交（当前会话）
SET @@autocommit = 0;
-- 执行 SQL...
COMMIT;     -- 提交事务
ROLLBACK;   -- 回滚事务

-- 方式二：显式开启事务
BEGIN;      -- 或 START TRANSACTION;
-- 执行 SQL...
COMMIT;     -- 提交事务
ROLLBACK;   -- 回滚事务

-- 保存点（部分回滚）
SAVEPOINT sp1;
ROLLBACK TO SAVEPOINT sp1;
RELEASE SAVEPOINT sp1;   -- 删除保存点
```

## 3. 事务四大特性（ACID）

| 特性 | 全称 | 说明 | 实现技术 |
|------|------|------|----------|
| Atomicity | 原子性 | 事务不可再分，要么全做要么全不做 | Undo Log（回滚日志） |
| Consistency | 一致性 | 事务前后数据完整性约束保持一致 | 原子性 + 隔离性 + 持久性共同保证 |
| Isolation | 隔离性 | 多个事务并发执行时互不干扰 | 锁机制 + MVCC |
| Durability | 持久性 | 事务提交后数据永久保存在磁盘 | Redo Log（重做日志） |

## 4. 并发事务的三大问题

| 问题 | 英文 | 现象描述 | 示例场景 |
|------|------|----------|----------|
| 脏读 | Dirty Read | 读取到另一个事务未提交的数据 | T1 修改 A=100 但未提交，T2 读到 100，T1 回滚，T2 读到的是脏数据 |
| 不可重复读 | Non-Repeatable Read | 同一事务内两次读取同一条记录的结果不同 | T1 查 A=50，T2 修改 A=100 提交，T1 再查 A=100 |
| 幻读 | Phantom Read | 同一事务内两次查询结果集行数不同 | T1 查 id>10 有 3 条，T2 插入 id=11 提交，T1 再查有 4 条 |

> **特别注意**：MySQL InnoDB 在 RR 级别下，快照读（普通 SELECT）无幻读问题，但当前读（`SELECT ... FOR UPDATE` / `UPDATE` / `DELETE`）仍需警惕幻读。

## 5. 事务隔离级别

### 5.1 四种隔离级别对比

| 隔离级别 | 脏读 | 不可重复读 | 幻读 | 并发性能 | 实现原理 |
|----------|:----:|:----------:|:----:|:--------:|----------|
| READ UNCOMMITTED | 可能 | 可能 | 可能 | 最高 | 不加锁，读未提交 |
| READ COMMITTED | 避免 | 可能 | 可能 | 较高 | 每条 SELECT 生成新 ReadView |
| REPEATABLE READ（MySQL 默认） | 避免 | 避免 | 部分解决 | 中等 | 事务内复用首次 ReadView + 间隙锁 |
| SERIALIZABLE | 避免 | 避免 | 避免 | 最低 | 所有读操作自动加共享锁，事务串行执行 |

### 5.2 相关 SQL 命令

```sql
-- 查看当前事务隔离级别
SELECT @@transaction_isolation; 

-- 设置隔离级别
SET SESSION TRANSACTION ISOLATION LEVEL READ COMMITTED; -- 当前会话
SET GLOBAL TRANSACTION ISOLATION LEVEL REPEATABLE READ; -- 全局
```
