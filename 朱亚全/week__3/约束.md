# MySQL 约束全面总结

---

## 1. 约束概述

约束是作用于表中字段上的规则，用于限制存储在表中的数据，保证数据的**正确性、有效性和完整性**。

---

## 2. 常见约束类型

| 约束 | 关键字 | 说明 |
|------|--------|------|
| 非空约束 | `NOT NULL` | 字段值不能为 NULL |
| 唯一约束 | `UNIQUE` | 字段值唯一，允许一个 NULL |
| 主键约束 | `PRIMARY KEY` | 非空 + 唯一，一张表只能有一个 |
| 自增约束 | `AUTO_INCREMENT` | 主键自动递增（配合 PRIMARY KEY） |
| 默认约束 | `DEFAULT` | 未指定值时使用默认值 |
| 检查约束 | `CHECK` | 限制字段值的范围/条件（MySQL 8.0 支持） |
| 外键约束 | `FOREIGN KEY` | 关联其他表，保证数据一致性 |

---

## 3. 建表示例（含约束）

```sql
CREATE TABLE user (
    id INT PRIMARY KEY AUTO_INCREMENT COMMENT '主键',
    name VARCHAR(20) NOT NULL UNIQUE COMMENT '姓名',
    age INT CHECK (age > 0 AND age <= 120) COMMENT '年龄',
    status CHAR(1) DEFAULT '1' COMMENT '状态',
    gender CHAR(1) COMMENT '性别'
) COMMENT '用户表';
```

### 约束说明

| 字段 | 约束 | 含义 |
|------|------|------|
| `id` | `PRIMARY KEY AUTO_INCREMENT` | 主键，自动递增 |
| `name` | `NOT NULL UNIQUE` | 不能为空，且唯一 |
| `age` | `CHECK (age > 0 AND age <= 120)` | 年龄必须在 1~120 之间 |
| `status` | `DEFAULT '1'` | 不指定时默认为 `'1'` |

## 4. 插入数据测试

```sql
-- 查看所有表
SHOW TABLES;

-- 查看表数据
SELECT * FROM user;

-- 插入数据（指定所有字段）
INSERT INTO user (name, age, status, gender) VALUES 
    ('张三', 20, 1, '男'),
    ('李四', 25, 1, '男');

-- 插入数据（status 使用默认值）
INSERT INTO user (name, age, gender) VALUES 
    ('王五', 18, '女');

-- 批量插入
INSERT INTO user (name, age, status, gender) VALUES 
    ('赵六', 25, 0, '女'),
    ('孙七', 27, 0, '女');
```

## 5. 外键约束（FOREIGN KEY）

### 5.1 外键基本概念

外键用于建立表与表之间的关联，被关联的字段必须是**主键**或**唯一键**。

### 5.2 创建状态表并关联

```sql
-- 创建状态表
CREATE TABLE cur_sta (
    status INT COMMENT '状态',
    descr VARCHAR(10) COMMENT '描述'
) COMMENT '状态表';

-- 插入状态数据
INSERT INTO cur_sta (status, descr) VALUES 
    (1, '状态满满'),
    (0, '状态很差');

-- 为 status 字段添加唯一约束（被外键引用必须为主键或唯一键）
ALTER TABLE cur_sta ADD UNIQUE (status);

-- 修改 user 表的 status 字段类型（与 cur_sta.status 保持一致）
ALTER TABLE user MODIFY status INT;

-- 添加外键约束
ALTER TABLE user ADD CONSTRAINT user_constraint 
    FOREIGN KEY (status) REFERENCES cur_sta(status);
```

### 5.3 外键删除与修改

```sql
-- 查看建表语句
SHOW CREATE TABLE user;

-- 删除外键约束
ALTER TABLE user DROP FOREIGN KEY user_constraint;

-- 重新添加外键（带级联操作）
ALTER TABLE user ADD CONSTRAINT user_constraint 
    FOREIGN KEY (status) REFERENCES cur_sta(status) 
    ON UPDATE CASCADE 
    ON DELETE CASCADE;
```

---

## 6. 外键约束选项

| 选项 | 说明 |
|------|------|
| `NO ACTION` | 不允许级联操作（默认） |
| `RESTRICT` | 不允许级联操作（默认） |
| `CASCADE` | 级联更新/删除（主表变，子表跟着变） |
| `SET NULL` | 主表删除/更新时，子表外键设为 NULL |

### 6.1 级联测试

```sql
-- 删除 cur_sta 表中 status = 0 的数据
-- 由于 ON DELETE CASCADE，user 表中 status = 0 的记录也会被同步删除
DELETE FROM cur_sta WHERE status = 0;
```

## 7. 约束管理命令速查

### 添加约束

```sql
-- 添加唯一约束
ALTER TABLE 表名 ADD UNIQUE (字段名);

-- 添加主键约束
ALTER TABLE 表名 ADD PRIMARY KEY (字段名);

-- 添加外键约束
ALTER TABLE 表名 ADD CONSTRAINT 外键名 
    FOREIGN KEY (字段名) REFERENCES 主表(字段名);

-- 添加检查约束（MySQL 8.0）
ALTER TABLE 表名 ADD CONSTRAINT 约束名 CHECK (条件);

-- 修改默认值
ALTER TABLE 表名 ALTER 字段名 SET DEFAULT 默认值;
```

### 删除约束

```sql
-- 删除外键约束
ALTER TABLE 表名 DROP FOREIGN KEY 外键名;

-- 删除主键约束
ALTER TABLE 表名 DROP PRIMARY KEY;

-- 删除唯一约束
ALTER TABLE 表名 DROP INDEX 字段名;

-- 删除默认值
ALTER TABLE 表名 ALTER 字段名 DROP DEFAULT;
```

## 8. 完整语法示例

### 创建表时指定外键

```sql
CREATE TABLE 子表 (
    id INT PRIMARY KEY AUTO_INCREMENT,
    status INT,
    -- 方式一：内联定义（简洁）
    FOREIGN KEY (status) REFERENCES 主表(字段名)
);

-- 或方式二：独立定义（可指定外键名）
CREATE TABLE 子表 (
    id INT PRIMARY KEY AUTO_INCREMENT,
    status INT,
    CONSTRAINT fk_status FOREIGN KEY (status) REFERENCES 主表(字段名)
);
```

### 修改表时添加外键

```sql
ALTER TABLE 子表 ADD CONSTRAINT fk_status 
    FOREIGN KEY (status) REFERENCES 主表(字段名)
    ON UPDATE CASCADE 
    ON DELETE SET NULL;
```

## 9. 约束对照表

| 约束类型 | 关键字 | 可添加位置 | MySQL 版本要求 |
|----------|--------|-----------|---------------|
| 非空约束 | `NOT NULL` | 建表 / `ALTER MODIFY` | 全部 |
| 唯一约束 | `UNIQUE` | 建表 / `ALTER ADD` | 全部 |
| 主键约束 | `PRIMARY KEY` | 建表 / `ALTER ADD` | 全部 |
| 自增约束 | `AUTO_INCREMENT` | 建表 / `ALTER MODIFY` | 全部 |
| 默认约束 | `DEFAULT` | 建表 / `ALTER ALTER` | 全部 |
| 检查约束 | `CHECK` | 建表 / `ALTER ADD` | MySQL 8.0+ |
| 外键约束 | `FOREIGN KEY` | 建表 / `ALTER ADD` | 全部（InnoDB） |
