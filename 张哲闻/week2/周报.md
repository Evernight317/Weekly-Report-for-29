## 二、遇到的问题与解决

**问题**：练习 update 的时候忘了写 where，把整张表的数据全改了。

**解决**：以后写 update / delete 先把 where 条件拿去 select 跑一遍确认影响范围，再执行。开事务手动 commit 的习惯也养起来了。

**问题**：group by 之后想筛分组结果，直接在 where 里写聚合条件报错了。

**解决**：where 在分组之前执行，筛分组结果要用 having。逻辑执行顺序是 from → where → group by → having → select → order by。
