## 一、本周学习概览

这周开始看 website 项目的代码，先从用户模块啃起。说实话第一周看真实项目比看教程累多了，教程的代码是给初学者设计的，项目代码里到处是不认识的写法：

- **分层结构**：先花了两三天理清 controller / service / mapper 的调用链，配合接口文档一个个方法跟进去，才大致知道一个请求是怎么流转的。
- **user_account 表**：四层铺垫里没接触过的东西不少——主键不是自增而是雪花 ID（ASSIGN_ID），密码存的是 BCrypt 哈希，邮箱、手机号、学号全是唯一索引。
- **注册链路**：参数校验 → 唯一性检查 → 验证码校验 → 落库，最后是"注册即登录"。改密码、改手机号这些敏感操作都要验证码，邮箱则干脆设计成不可修改。
- **缓存**：第一次见到 cache-aside 模式，用户资料读多改少，走 Redis 缓存，TTL 30 分钟。查不到的 id 会写一个 `__NULL__` 哨兵占位，听说是防缓存穿透的。

## 二、遇到的问题与解决

**问题**：方法一跳跳四五层，跟到一半就忘了自己从哪进来的。

**解决**：后来学乖了，用断点跑起来跟着调用栈走，比纯肉眼翻代码快很多。辅助以先看接口文档知道功能，再顺着功能找代码。

**问题**：不明白为什么改个用户名不能直接 update 完事，代码里又是查缓存又是删缓存。

**解决**：翻了资料才知道数据库和缓存双写会有不一致的窗口，先更新库再删缓存是相对稳的做法，项目里还有延迟双删，这个准备下周再仔细看。
