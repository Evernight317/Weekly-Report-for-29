## 一、本周学习概览

这周从 Linux 入手，主要跟着 docs 里的速通教程在终端上边敲边练：

- **目录与文件操作**：把 /etc、/var/log、/home 这些常用目录过了一遍，ls / cd / cp / mv / rm 基本能形成肌肉记忆了，ls -lh 看文件大小挺好用。
- **权限**：chmod / chown 弄明白了 r w x 对应 4 2 1，一开始看到 755 这种数字一脸懵，现在知道怎么算了。
- **管道与重定向**：重点搞懂了 `|`、`>`、`>>` 和 2>&1。以前只知道 `>` 是覆盖，这周才把 stdin / stdout / stderr 和文件描述符 0 / 1 / 2 的关系理顺，`ps -ef | grep java` 这种组合命令终于看懂了。
- **文本处理**：grep 用得最多，sed 和 awk 只会最简单的替换和取列，够用但不熟。
- **进程相关**：ps / kill / nohup，试着用 nohup 把一个程序挂到后台跑，断开 ssh 也不会死。

## 二、遇到的问题与解决

**问题**：vim 打开文件之后退不出去，第一次卡在里面半天只能关掉终端。

**解决**：先背了 `:wq` 和 `:q!` 两个命令保命，后面又练了几次 i / Esc 的切换，现在能自己改配置文件了。

**问题**：`command > file 2>&1` 写成 `command 2>&1 > file`，结果错误信息还是跑到终端上。

**解决**：查了资料才知道重定向是从左往右按顺序生效的，顺序不同结果不一样，这个坑记住了。
