## 一、本周学习概览

这周进入 JavaWeb，内容比前两周杂：

- **Maven**：依赖管理、坐标、scope 作用域，配置了阿里云镜像。自己建了个工程练手，搞清楚了父子模块之间的关系。
- **Servlet 与 HTTP**：Tomcat 的目录结构、Servlet 的生命周期、request / response 的用法。用 Servlet 手写了个简陋的登录接口，对 HTTP 请求响应的流程算是有了体感。
- **Filter 与 Listener**：Filter 的过滤链流程过了一遍，知道它和后面 Spring 里的拦截器有点像但不是一个东西。
- **Spring Boot 入门**：跟着速通教程搭了第一个 Spring Boot 项目，三层架构 controller / service / mapper，参数用 @RequestBody / @RequestParam 接，比手写 Servlet 舒服太多了。

## 二、遇到的问题与解决

**问题**：Maven 拉依赖一直卡在 downloading 不动，还以为是自己网络的问题。

**解决**：换成阿里云镜像，把 settings.xml 里的 mirror 配好之后就正常了。

**问题**：接口一直 404，controller 代码看了半天没毛病。

**解决**：最后发现是启动类放的位置不对，@SpringBootApplication 默认只扫自己所在包及子包，扫描不到 controller，调一下目录结构就好了。
