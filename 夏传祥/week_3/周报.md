## 二、核心学习内容

### 2.1 前端工程化与 Ajax

- **Ajax 与 Axios**：理解了异步请求的基本原理，学习了 Axios 库的常用 API（get、post、请求拦截器等），能够通过 Axios 在 Vue 项目中发起 HTTP 请求并处理响应数据。

- **前端工程化**：学习了 Vue 脚手架（Vue CLI）的项目结构，熟悉了 `src/main.js` 入口文件、`components` 组件目录、`router` 路由目录的组织方式，理解了 `npm run serve` 的开发流程和 `npm run build` 的打包部署流程。

- **Element UI 组件库**：
    - 掌握了常用组件的使用：Table 表格、Pagination 分页、Dialog 对话框、Form 表单
    - 能够基于 Element 组件搭建后台管理页面的基本布局（侧边栏 + 头部 + 主内容区）
    - 完成了结合 Axios 异步加载数据并渲染到 Table 组件的综合案例

- **Vue Router**：学习了前端路由的概念与配置方式，理解了单页面应用（SPA）中路由跳转的实现原理。

### 2.2 Maven 依赖管理

- **Maven 概述与安装**：理解了 Maven 作为项目构建与依赖管理工具的核心价值，完成了本地安装与环境变量配置。

- **IDEA 集成 Maven**：掌握了在 IDEA 中配置本地 Maven 路径、创建 Maven 项目、导入已有 Maven 项目的操作流程。

- **依赖管理**：
    - 学习了 `pom.xml` 中依赖坐标（groupId、artifactId、version）的声明方式
    - 理解了依赖传递机制（直接依赖与间接依赖）以及依赖范围（compile、runtime、test、provided）的区别
    - 熟悉了 Maven 生命周期（clean、compile、test、package、install）各阶段的作用

### 2.3 SpringBoot 快速入门

- **SpringBoot 项目创建**：使用 Spring Initializr 创建了第一个 SpringBoot 项目，理解了 `@SpringBootApplication` 注解的核心作用。

- **HTTP 协议**：
    - 学习了 HTTP 请求报文的格式（请求行、请求头、请求体）
    - 掌握了 HTTP 响应状态码的分类（1xx~5xx）及常见状态码的含义（200、302、400、404、500）
    - 了解了 GET 与 POST 请求的典型使用场景差异

- **Tomcat**：理解了 Tomcat 作为 Web 容器的作用，学习了内嵌 Tomcat 的工作方式，明确了 SpringBoot 项目内置 Tomcat 带来的便利——无需单独部署。

### 2.4 请求响应与分层解耦

- **请求参数接收**：
    - 简单参数：通过 `@RequestParam` 接收 URL 参数
    - 实体参数：通过 `@RequestBody` 将 JSON 自动封装为实体对象
    - 数组/集合参数：通过 `@RequestParam` 接收同名多值参数
    - 日期参数：通过 `@DateTimeFormat` 指定日期格式
    - 路径参数：通过 `@PathVariable` 获取 RESTful 风格的路径变量

- **响应封装**：学习了 `@ResponseBody` 的作用，掌握了统一响应结果类（Result）的设计模式，通过 `code`、`message`、`data` 三个字段规范化接口返回值。

- **三层架构**：
    - Controller（控制层）：接收请求、调用 Service、返回响应
    - Service（业务层）：处理业务逻辑
    - Dao / Mapper（数据访问层）：负责数据库操作
    - 理解了分层设计的核心优势：职责分离、易于维护、方便复用

- **IOC 与 DI**：
    - IOC（控制反转）：将对象的创建权交给 Spring 容器管理，通过 `@Component`、`@Controller`、`@Service`、`@Repository` 将类注册为 Bean
    - DI（依赖注入）：通过 `@Autowired` 实现依赖的自动注入，容器会自动查找并注入所需 Bean

### 2.5 MySQL 数据库（DDL 与 DML）

- **数据库概述与安装**：完成了 MySQL 的安装与配置，理解了关系型数据库的基本数据模型（库 → 表 → 行/列）。

- **DDL（数据定义语言）**：
    - 数据库操作：`CREATE DATABASE`、`DROP DATABASE`、`USE`
    - 表结构操作：`CREATE TABLE`、`ALTER TABLE`、`DROP TABLE`、`TRUNCATE TABLE`
    - 数据类型：熟悉了 `int`、`bigint`、`varchar`、`char`、`date`、`datetime`、`decimal` 等常用类型的选择场景
    - 图形化工具：使用 DataGrip 进行可视化管理，提升操作效率

- **DML（数据操作语言）**：
    - `INSERT INTO ... VALUES ...` 插入数据，及批量插入的写法
    - `UPDATE ... SET ... WHERE ...` 修改数据，强调 WHERE 条件的重要性
    - `DELETE FROM ... WHERE ...` 删除数据，以及逻辑删除与物理删除的区别

## 四、问题与解决方案

| 问题 | 解决方案 |
|------|----------|
| Vue 项目中 Axios 请求跨域报错（CORS） | 在 SpringBoot 后端添加 `@CrossOrigin` 注解允许跨域访问，同时了解了 CORS 的原理（浏览器同源策略限制） |
| `@Autowired` 注入时报 "Field required a bean of type that could not be found" | 检查 Service 类是否添加了 `@Service` 注解，确保该类已被 Spring 容器管理 |
| MySQL 创建表时中文字段注释显示乱码 | 建库时指定字符集 `CHARACTER SET utf8mb4`，在连接 URL 中添加 `useUnicode=true&characterEncoding=utf-8` |
| Maven 依赖冲突导致编译报错 | 使用 `mvn dependency:tree` 查看依赖树，在 `pom.xml` 中通过 `<exclusions>` 排除多余的传递依赖 |
| SpringBoot 接口返回 JSON 时日期格式不理想 | 在实体类的日期字段上添加 `@JsonFormat(pattern = "yyyy-MM-dd")` 注解统一日期格式 |

## 六、总结与思考

本周是进入 Java Web 阶段以来内容密度最高的一周，从前端到后端、从请求到响应、从容器到数据库，知识跨度很大。回顾本周，有以下几点体会：

- **框架设计思想比具体语法更重要**：学习 IOC/DI 和三层架构时，起初只觉得是多写几个注解、多建几个包。但在亲手将代码从一团揉在一起的状态重构为分层结构后，才真正理解"解耦"的价值——每层各司其职、改动一处不影响其他层。这种设计思想比记住注解名称更有意义。

- **前后端要放在一起学**：本周前端 Ajax + 后端 SpringBoot 结合练习时，第一次看到前端页面通过 HTTP 请求把数据展示在浏览器上，真切感受到了"前后端联动"的完整闭环。单纯学前端或单纯学后端都无法建立这种全局视角。

- **MySQL 需要反复动手**：DDL 和 DML 的语法不难，但数据类型选择、建表规范、SQL 书写习惯这些需要大量练习才能真正内化。下周 DQL 多表查询是 SQL 能力的核心考验，需要多刷练习。

整体进度与预期基本一致，下周将重点攻克 DQL 多表查询，为后续 MyBatis 的学习做好数据库基础铺垫。
